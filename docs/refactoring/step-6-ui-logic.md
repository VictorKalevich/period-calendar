# Шаг 6. Решения — в чистых функциях, компоненты только рисуют

Приоритет: низкий. Зависимости: шаги 3 и 4, если они выполняются (затрагивают те же файлы).
Видимых изменений нет: разметка должна совпасть посимвольно.
Общие правила и порядок работы — `docs/refactoring-roadmap.md`.

## Проблема

Проект уже выносит решения в домен (`dayDialogFor`, `visibleEntryParts`, `periodActionsFor`) и
тестирует их без DOM. Но часть решений осталась внутри компонентов, а слой `.tsx` — 27 файлов,
около 1 900 строк — покрыт одним тестом (`ForecastInfo.test.ts`).

1. **Чистые функции-дубли в файлах компонентов:**
   - `pluralRu` (`src/ui/components/BackupSection.tsx:11-16`) повторяет правило склонения из
     `formatShiftRu` (`src/domain/dates.ts:90-97`);
   - `numericDate` (`BackupSection.tsx:19`) совпадает с `formatDateNumeric`
     (`src/domain/report.ts:143`);
   - `fullDate` (`src/ui/screens/StatsScreen.tsx:12`) повторяет формат из `formatRangeRu`
     (`dates.ts:82`), и ради неё экран импортирует `date-fns` напрямую (`StatsScreen.tsx:1-2`) —
     единственное такое место вне домена.
2. **Решения без тестов внутри компонентов:**
   - выбор вида импортируемого файла — резервная копия, текстовая выгрузка или «не распознан»
     (`BackupSection.tsx:40-64`);
   - переходы состояния листа «Самочувствие»: отметка пункта, степень по умолчанию, снятие пункта
     вместе со степенью (`src/ui/components/SymptomPicker.tsx:28-50`);
   - правило переключателей напоминаний: выключен последний — отписаться, включён при отсутствии
     подписки — подписаться (`src/ui/components/RemindersSection.tsx:33-38`, 007 FR-008).
3. **Разметка переключателя скопирована 10 раз**: 7 в `SettingsScreen.tsx:43-145` и 3 в
   `RemindersSection.tsx:68-106`. Для счётчика компонент есть (`Stepper`), для переключателя — нет,
   хотя в дизайн-системе это компонент (`docs/design/design.md`, «Переключатель `toggle`»).
4. **Тесты `.test.tsx` не запускаются**: `vitest.config.ts:10` включает только `src/**/*.test.ts`.

## Цель

Решения из п. 2 — чистые функции с тестами; у каждой вспомогательной функции одно определение;
переключатель — один компонент.

## Набросок решения

1. Перенести `pluralRu` в домен и использовать в `formatShiftRu`; числовой формат даты — одна
   функция в `src/domain/dates.ts`; полная дата «8 ноября 2026» — функция в `dates.ts`;
   `StatsScreen` больше не импортирует `date-fns`.
2. Чистые функции с тестами: вид импортируемого файла по тексту; переходы состояния
   «Самочувствия» (отметить, снять, задать степень, начальное состояние); действие при
   переключении напоминания (`отписаться` / `подписаться` / `ничего`).
3. Компонент `Toggle` (подпись, необязательная подсказка, состояние, `disabled`,
   `aria-describedby`) с прежней разметкой; десять мест используют его.

## Проверить на этапе плана

- **Совпадение разметки.** До замены зафиксировать тестом через `renderToStaticMarkup` разметку
  переключателя во всех вариантах (с подсказкой и без, `disabled`, `aria-describedby`), затем
  получить ту же строку от `Toggle`. Экраны с `useLiveQuery` серверной отрисовкой не проверить
  (эффекты не выполняются) — проверять компонент отдельно.
- Куда класть чистые функции интерфейса: правила про данные — в `src/domain`; правила, знающие о
  браузере (разрешение уведомлений), — рядом с компонентом в `src/ui` отдельным `.ts`-файлом.
- Если `pluralRu` импортируют тесты — менять только путь импорта.

## Границы

Входит: пункты 1–3 наброска; при необходимости — включение `*.test.tsx` в `vitest.config.ts`.

Не входит: `MonthPager` и прокрутка календаря, `BottomSheet`, изменение текстов, классов и
порядка элементов, новые компоненты кроме `Toggle`, DOM-окружение для тестов.

## Критерии готовности

- Тесты новых чистых функций написаны до кода.
- В `src/ui` нет импорта `date-fns` и нет собственных функций склонения и форматирования дат.
- Разметка переключателей посимвольно прежняя (тест из «Проверить на этапе плана»).
- `SymptomPicker`, `BackupSection`, `RemindersSection` вызывают чистые функции; поведение прежнее.
- `ForecastInfo.test.ts`, `design-system.test.ts`, `theme.test.ts` не изменены и зелёные.
- `npm test` и `npm run build` зелёные.
