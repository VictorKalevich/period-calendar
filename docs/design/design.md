# Дизайн: Календарь цикла

Согласованные макеты (холст «Календарь цикла» в claude.ai, 23.10.2026). Этот файл — источник
правды для UI-задач: цвета, типографика, размеры и состав экранов. Отклонения согласовываются
с владельцем проекта.

- Настроение: мягкий, нежный; много воздуха, крупные скругления, без градиентов и эмодзи.
- Экран по умолчанию при запуске — **Календарь** (основной макет). Экрана «Сегодня» нет.
- Размер макетов: 390×844 (iPhone), поля по бокам 20 px, вертикальный шаг между блоками 14 px.
- Единицы: CSS px (в iOS Safari 1 CSS px = 1 pt). Минимальная зона нажатия — 44 px.

## Скругления и размеры

- Карточки: radius 24.
- Кнопки-пилюли: высота 44–54, radius = половина высоты.
- Круглые иконочные кнопки: 44×44.
- Ячейка календаря: круг 40×40 внутри строки высотой 44; сетка 7 колонок, промежуток строк 4.
- Иконки: inline SVG, обводка `currentColor`, 1.8–2 px, 20–22 px.

## Экран «Календарь» (основной, открывается первым)

Сверху вниз:
0. Подсказка (фича 010) — только пока нет ни одной отметки месячных и её не закрыли крестиком:
   карточка `roseSoft` на всю ширину, radius 24, отступы 16/18, без тени. Заголовок «Как получить
   прогноз» 15 px 800 `roseText`; ниже текст 14 px 600 `roseText`, line-height 1.45: «Отметьте, когда
   начались последние месячные: нажмите на этот день в календаре — прошедшие дни тоже можно — и
   выберите «Начало месячных».» и вторым абзацем «Историю из другого приложения можно загрузить в
   Настройках → «Резервная копия».» Справа сверху — круглая кнопка-крестик 44×44 без фона, иконка
   20 px `roseText` (обводка 2 px), подпись для экранного диктора «Скрыть подсказку»; заголовок не
   заходит под крестик. Исчезает сразу после первой отметки месячных; закрытая крестиком больше не
   появляется на этом устройстве. Переключателя в Настройках нет.
1. Шапка: круглая кнопка «‹» — «Октябрь 2026» по центру — круглая кнопка «›».
2. Плашка-пилюля по центру, шаблон «Сегодня N-й день · вероятность {низкая|средняя|высокая}»
   (короткая форма без слова «зачатия» — из-за ширины пилюли), `violetSoft` / `violetText`.
   При задержке — «Задержка N дн.» (`roseSoft` / `roseText`). Без данных — приглашение отметить месячные.
   Если прогноз низкой уверенности — под плашкой строка 12 px `muted`: «Прогноз по средним значениям,
   станет точнее после нескольких циклов».
3. Карточка `surface` с сеткой месяца: строка «Пн … Вс» (12 px, `muted`), затем 5–6 строк дней.
   Свайп влево/вправо листает месяцы как pager: соседний месяц тянется за пальцем, привязка к странице.
4. Легенда — сетка 2 колонки (13 px, `muted`), строк — по числу пунктов, значок 14 px слева от подписи:
   - Месячные — круг с заливкой `btnBg`;
   - Месячные (прогноз) — круг с пунктирной обводкой `rose`;
   - Фертильное окно — круг `violetSoft` с пунктирной обводкой `violetMid`;
   - Овуляция — иконка короны;
   - Сегодня — круг с обводкой `ink`;
   - Есть записи — точка `muted` (только если в Настройках включено «Самочувствие», «Настроение» или
     «Заметки»);
   - Секс — сердечко (только если включена «Отметка секса», фича 009).
5. Карточка выбранного дня (показывается под календарём, не всплывает; по умолчанию выбран сегодняшний день):
   «24 октября · 10-й день», ниже — фаза цикла 14 px 700 `muted` («Фолликулярная фаза»; при задержке
   и без данных не показывается), сводка записей (только включённых типов; фича 009 — в одну строку
   с переносом: пилюля «Секс» с сердечком 14 px (`roseSoft` / `roseText`), затем пилюли самочувствия
   (`violetSoft` / `violetText`, при включённой интенсивности — «Головная боль · сильно»), затем
   пилюли настроений (те же цвета); ниже — заметка). Пилюли вероятности и строки
   пояснения нет (фича 005) — вероятность видна в плашке над календарём. Кнопок в карточке нет.
   **Диалог дня** — нижний лист по нажатию на дату, заголовок — дата («24 октября»):
   - кнопки месячных (только сегодня и прошлые дни; specs/003-calendar-tap-actions, ревизия 2): первый
     день — «Удалить период» с подтверждением «Удалить месячные {начало}–{конец}?» («Удалить» / «Отмена»);
     следующие дни — «Отметить конец в этот день», «Установить как начало»; вне месячных — «Начало
     месячных» и условные «Продлить месячные до …», «Установить как начало месячных»;
   - фича 009: «Отметить секс» (или «Убрать отметку секса», если отметка есть) — обычная пилюля с
     сердечком 18 px слева от текста; только сегодня и прошлые дни и только при включённой «Отметке
     секса»; нажатие сразу сохраняет и закрывает лист;
   - затем «Самочувствие», «Настроение» и «Заметки» — если включены в Настройках; открывают выбор
     самочувствия, выбор настроения и редактор заметки для этой даты. «Самочувствие» и «Настроение» —
     только сегодня и прошлые дни (фича 012);
   - «Отмена».
   **Кнопка записи с данными** (фича 012, правило для всех кнопок записей дня, в том числе будущих):
   если у дня уже есть запись этого типа, кнопка выделена как нажатый чип — фон и рамка `violetSoft`,
   текст `violetText`, 800; для экранного диктора к подписи добавляется «, есть записи».
   Будущий день: лист открывается, только если включены «Заметки» (тогда в нём только «Заметки» и
   «Отмена»), иначе день просто выбирается. Даты не выделяются и не вызывают лупу/меню/синюю подсветку
   iOS. Кнопки листа — пилюли 52–54 px, первая — главная (`btnBg`), «Отмена» — без фона.
6. Пометки о прогнозе на экране нет (с 2026-10-24, Конституция 2.0.0). Лист «Как считается прогноз»
   открывается из Настроек (см. «Ещё не нарисовано»): длина цикла; овуляция — по включённому способу:
   на 14-й день цикла (начало месячных + 13 дней) или, при «Считать от следующей менструации»,
   примерно за 14 дней до ожидаемого начала следующих месячных, но не раньше дня после месячных;
   в обоих случаях не позже дня перед следующими месячными; фертильное окно — 5 дней до овуляции и
   день овуляции, в дни отмеченных месячных окно не показывается; уровни вероятности; правило низкой
   уверенности. Если личный сдвиг включён и не равен 0 — строка «Учтён ваш личный сдвиг овуляции:
   +2 дня (настраивается в Настройках)» (в обоих способах).
   Пока любой лист открыт, страница под ним не прокручивается и не нажимается; длинный лист
   прокручивается сам, после закрытия позиция страницы восстанавливается.
   При открытии листа ни один его элемент не обведён (фича 012): у чипов, сегментов и кнопок только два
   вида — нажата / не нажата; обводка `violet` 2 px — только при навигации внешней клавиатурой.
7. Нижняя навигация.

## Нижняя навигация

Фон `surface`, верхняя граница 1 px `line`, отступы 8/12/20. Три равные вкладки (иконка 22 + подпись 12):
Календарь (календарик) · Статистика (три столбика) · Настройки (два ползунка). Экран и вкладка «Сегодня»
(бывший макет C) удалены; сохранённая в адресе старая вкладка открывает «Календарь».
Активная — `roseText`, 800; остальные — `muted`, 600.

## Главная кнопка действия

Высота 54, radius 27, фон `btnBg`, текст `btnInk` 17/800, иконка капли слева.

## Ещё не нарисовано

Статистика, Настройки, листы «Самочувствие» и «Настроение», редактор заметки, экран «добавьте
на экран Домой». До появления макетов — собирать из токенов и компонентов выше (карточки `surface`,
пилюли, те же размеры шрифтов), без новых цветов. Слово «Симптомы» в интерфейсе не используется —
только «Самочувствие».

Карточка «Записи дня» (фичи 004, 009). Текст под заголовком: «Включите то, что хотите отмечать в
диалоге дня. Выключение ничего не удаляет — записи просто скрываются.» Переключатели по порядку (все по
умолчанию выключены):
- «Самочувствие»;
- «Интенсивность самочувствия» — только когда «Самочувствие» включено, сразу под ним; подпись 13 px
  `muted` «Слабо, средне или сильно — для каждой отметки самочувствия»;
- «Настроение» — подпись «Можно выбрать несколько»;
- «Отметка секса» — подпись «Сердечко в календаре»;
- «Заметки».

Лист «Самочувствие» (фича 009): заголовок «Самочувствие · 24 октября», чипы самочувствия (`chip`,
несколько), без настроений. При включённой интенсивности под чипами — подзаголовок «Интенсивность»
(как у группы чипов) и по строке на каждый отмеченный пункт в порядке списка: подпись 15 px 700 `ink`,
под ней три сегмента «слабо», «средне», «сильно» в ряд на всю ширину (высота 44, radius 22, фон `bg`,
рамка 1 px `line`, текст 14 px 700 `muted`; выбранный — как выбранный чип: `violetSoft` / `violetText`,
800). У отмеченного пункта всегда выбрана ровно одна степень: при отметке — «средне», у сохранённых
пунктов без степени при открытии листа тоже «средне» (фича 012); повторное нажатие на выбранную степень
её не снимает. Внизу — «Готово» (главная кнопка).

Редактор заметки (фича 012): справа в шапке листа, на одной линии с заголовком «Заметка · 24 октября», —
круглая кнопка-корзина 44×44 без фона, иконка 20 px `roseText`, подпись для диктора «Удалить заметку»;
видна, только если у дня есть сохранённая заметка. Нажатие показывает в том же листе подтверждение:
заголовок «Удалить заметку?», текст 15 px «Заметка за 24 октября будет удалена.», кнопки «Удалить»
(главная) и «Отмена» (без фона). Текстовой кнопки «Удалить заметку» нет.

Лист «Настроение» (фича 009): заголовок «Настроение · 24 октября», 20 чипов настроения в порядке
справочника (несколько; без эмодзи), «Готово».

Карточка «Цикл» (фича 006): «Длина цикла по умолчанию», «Длина месячных по умолчанию», затем
переключатель «Учитывать личный сдвиг овуляции» (по умолчанию выключен); когда включён — подсказка
13 px `muted` «Настройте, на сколько дней ваша овуляция обычно раньше или позже расчётной даты.» и
счётчик «Сдвиг овуляции» −5…+5 («−5 дней» … «0 дней» … «+5 дней», минус U+2212) с круглыми кнопками
44 px; ячейка значения фиксированной ширины под «−5 дней», цифры `tabular-nums`, на границах кнопка
неактивна. Выключение сохраняет выбранное значение. Ниже (под счётчиком, если он показан), всегда
