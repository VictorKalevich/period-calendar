# Дизайн: Календарь цикла

Согласованные макеты (холст «Календарь цикла» в claude.ai, 23.10.2026). Этот файл — источник
правды для UI-задач: цвета, типографика, размеры и состав экранов. Отклонения согласовываются
с владельцем проекта.

- Настроение: мягкий, нежный; много воздуха, крупные скругления, без градиентов и эмодзи.
- Экран по умолчанию при запуске — **Календарь** (основной макет). Экрана «Сегодня» нет.
- Размер макетов: 390×844 (iPhone), поля по бокам 20 px, вертикальный шаг между блоками 14 px.
- Единицы: CSS px (в iOS Safari 1 CSS px = 1 pt). Минимальная зона нажатия — 44 px.

## Скругления и размеры

- Карточки: radius 24.
- Кнопки-пилюли: высота 44–54, radius = половина высоты.
- Круглые иконочные кнопки: 44×44.
- Ячейка календаря: круг 40×40 внутри строки высотой 44; сетка 7 колонок, промежуток строк 4.
- Иконки: inline SVG, обводка `currentColor`, 1.8–2 px, 20–22 px.

| Месячные (отмечено) | заливка `btnBg`, текст `btnInk`, 800 |
| Месячные (прогноз) | пунктирная обводка 2 px `rose`, без заливки, текст `roseText`, 700 |

| Овуляция | заливка `goldSoft`, сплошная обводка 2 px `gold`, текст `ink`, 800, **корона** 18×18 над правым верхним краем круга (top −9, right −6) |
| Фертильное окно (прошлый цикл) | заливка `violetSoft` **без** пунктирной обводки, текст `violetText`, 600 — оценка задним числом |
| Овуляция (прошлый цикл) | как «Овуляция», но обводка 2 px `gold` сплошная и корона того же размера — без отличий |

Корона используется везде, где обозначается овуляция: календарь, легенда.

## Экран «Календарь» (основной, открывается первым)

Сверху вниз:
1. Шапка: круглая кнопка «‹» — «Октябрь 2026» по центру — круглая кнопка «›».
2. Плашка-пилюля по центру, шаблон «Сегодня N-й день · вероятность {низкая|средняя|высокая}»
   (короткая форма без слова «зачатия» — из-за ширины пилюли), `violetSoft` / `violetText`.
   При задержке — «Задержка N дн.» (`roseSoft` / `roseText`). Без данных — приглашение отметить месячные.
   Если прогноз низкой уверенности — под плашкой строка 12 px `muted`: «Прогноз по средним значениям,
   станет точнее после нескольких циклов».
3. Карточка `surface` с сеткой месяца: строка «Пн … Вс» (12 px, `muted`), затем 5–6 строк дней.
   Свайп влево/вправо листает месяцы как pager: соседний месяц тянется за пальцем, привязка к странице.
4. Легенда — сетка 2 колонки × 3 строки (13 px, `muted`), значок 14 px слева от подписи, все обозначения:
   - Месячные — круг с заливкой `btnBg`;
   - Месячные (прогноз) — круг с пунктирной обводкой `rose`;
   - Фертильное окно — круг `violetSoft` с пунктирной обводкой `violetMid`;
   - Овуляция — иконка короны;
   - Сегодня — круг с обводкой `ink`;
   - Есть записи — точка `muted` (только если в Настройках включено «Самочувствие» или «Заметки»).
5. Карточка выбранного дня (показывается под календарём, не всплывает; по умолчанию выбран сегодняшний день):
   «24 октября · 10-й день», ниже — фаза цикла 14 px 700 `muted` («Фолликулярная фаза»; при задержке
   и без данных не показывается), сводка записей (только включённых типов). Пилюли вероятности и строки
   пояснения нет (фича 005) — вероятность видна в плашке над календарём. Кнопок в карточке нет.
   **Диалог дня** — нижний лист по нажатию на дату, заголовок — дата («24 октября»):
   - кнопки месячных (только сегодня и прошлые дни; specs/003-calendar-tap-actions, ревизия 2): первый
     день — «Удалить период» с подтверждением «Удалить месячные {начало}–{конец}?» («Удалить» / «Отмена»);
     следующие дни — «Отметить конец в этот день», «Установить как начало»; вне месячных — «Начало
     месячных» и условные «Продлить месячные до …», «Установить как начало месячных»;
   - затем «Самочувствие» и «Заметки» — если включены в Настройках; открывают выбор самочувствия и
     редактор заметки для этой даты;
   - «Отмена».
   Будущий день: лист открывается, только если включено «Самочувствие» или «Заметки» (тогда без кнопок
   месячных), иначе день просто выбирается. Даты не выделяются и не вызывают лупу/меню/синюю подсветку
   iOS. Кнопки листа — пилюли 52–54 px, первая — главная (`btnBg`), «Отмена» — без фона.
6. Пометка 12 px `muted`: «Прогноз ориентировочный и не заменяет контрацепцию» (может быть в карточке дня).
   «Подробнее» открывает лист «Как считается прогноз»: длина цикла; овуляция — на 14-й день цикла
   (начало месячных + 13 дней), но не позже дня перед следующими месячными; фертильное окно — 5 дней до овуляции и день овуляции, в дни отмеченных
   месячных окно не показывается; уровни вероятности; правило низкой уверенности. Если личный сдвиг
   включён и не равен 0 — строка «Учтён ваш личный сдвиг овуляции: +2 дня (настраивается в Настройках)».
   Пока любой лист открыт, страница под ним не прокручивается и не нажимается; длинный лист
   прокручивается сам, после закрытия позиция страницы восстанавливается.
7. Нижняя навигация.

## Нижняя навигация

Фон `surface`, верхняя граница 1 px `line`, отступы 8/12/20. Три равные вкладки (иконка 22 + подпись 12):
Календарь (календарик) · Статистика (три столбика) · Настройки (два ползунка). Экран и вкладка «Сегодня»
(бывший макет C) удалены; сохранённая в адресе старая вкладка открывает «Календарь».
Активная — `roseText`, 800; остальные — `muted`, 600.

## Главная кнопка действия

Высота 54, radius 27, фон `btnBg`, текст `btnInk` 17/800, иконка капли слева.

## Ещё не нарисовано

Статистика, Настройки, лист «Самочувствие» (симптомы и настроение), редактор заметки, экран «добавьте
на экран Домой». До появления макетов — собирать из токенов и компонентов выше (карточки `surface`,
пилюли, те же размеры шрифтов), без новых цветов. В Настройках — карточка «Записи дня» с
переключателями «Самочувствие» и «Заметки» (по умолчанию выключены). Слово «Симптомы» в интерфейсе
не используется — только «Самочувствие». Под ними — переключатель «Учитывать личный сдвиг овуляции»
(по умолчанию выключен); когда включён — подсказка 13 px `muted` «Настройте, на сколько дней ваша
овуляция обычно раньше или позже расчётной даты.» и счётчик −5…+5 («−5 дней» … «0 дней» … «+5 дней»,
минус U+2212) с круглыми кнопками 44 px; ячейка значения фиксированной ширины под «−5 дней»,
цифры `tabular-nums`, на границах кнопка неактивна. Выключение сохраняет выбранное значение.
