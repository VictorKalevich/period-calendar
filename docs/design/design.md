# Дизайн: Календарь цикла

Согласованные макеты (холст «Календарь цикла» в claude.ai, 23.10.2026). Этот файл — источник
правды для UI-задач: цвета, типографика, размеры и состав экранов. Отклонения согласовываются
с владельцем проекта.

- Настроение: мягкий, нежный; много воздуха, крупные скругления, без градиентов и эмодзи.
- Экран по умолчанию при запуске — **Календарь** (основной макет). Вкладка «Сегодня» — макет C.
- Размер макетов: 390×844 (iPhone), поля по бокам 20 px, вертикальный шаг между блоками 14 px.
- Единицы: CSS px (в iOS Safari 1 CSS px = 1 pt). Минимальная зона нажатия — 44 px.

## Скругления и размеры

- Карточки: radius 24 (крупная карточка «Сегодня» — 28).
- Кнопки-пилюли: высота 44–54, radius = половина высоты.
- Круглые иконочные кнопки: 44×44.
- Ячейка календаря: круг 40×40 внутри строки высотой 44; сетка 7 колонок, промежуток строк 4.
- Иконки: inline SVG, обводка `currentColor`, 1.8–2 px, 20–22 px.

## Состояния дня в календаре

| Состояние | Вид |

| Обычный день | без заливки, текст `ink`, 600 |
| Месячные (отмечено) | заливка `btnBg`, текст `btnInk`, 800 |
| Месячные (прогноз) | пунктирная обводка 2 px `rose`, без заливки, текст `roseText`, 700 |
| Фертильное окно (прогноз) | заливка `violetSoft`, пунктирная обводка 2 px `violetMid`, текст `violetText`, 700 |
| Овуляция | заливка `goldSoft`, сплошная обводка 2 px `gold`, текст `ink`, 800, **корона** 18×18 над правым верхним краем круга (top −9, right −6) |
| Фертильное окно (прошлый цикл) | заливка `violetSoft` **без** пунктирной обводки, текст `violetText`, 600 — оценка задним числом |
| Овуляция (прошлый цикл) | как «Овуляция», но обводка 2 px `gold` сплошная и корона того же размера — без отличий |
| Сегодня | сплошная обводка 2 px `ink`, текст 800 (сочетается с другими состояниями) |
| Выбранный день | двойное кольцо: `0 0 0 3px surface, 0 0 0 5px violet` |

Корона (viewBox 0 0 24 24): `<path d="M3 8l4.5 4L12 5l4.5 7L21 8l-2 11H5z" fill="gold" stroke="goldDeep" stroke-width="1.6" stroke-linejoin="round"/>`.
Корона используется везде, где обозначается овуляция: календарь, легенда, «Сегодня».

## Экран «Календарь» (основной, открывается первым)

Сверху вниз:
1. Шапка: круглая кнопка «‹» — «Октябрь 2026» по центру — круглая кнопка «›».
2. Плашка-пилюля по центру, шаблон «Сегодня N-й день · вероятность {низкая|средняя|высокая}»
   (короткая форма без слова «зачатия» — из-за ширины пилюли), `violetSoft` / `violetText`.
   При задержке — «Задержка N дн.» (`roseSoft` / `roseText`). Без данных — приглашение отметить месячные.
   Если прогноз низкой уверенности — под плашкой строка 12 px `muted`: «Прогноз по средним значениям,
   станет точнее после нескольких циклов».
3. Карточка `surface` с сеткой месяца: строка «Пн … Вс» (12 px, `muted`), затем 5–6 строк дней.
   Свайп влево/вправо листает месяцы как pager: соседний месяц тянется за пальцем, привязка к странице.
4. Легенда — сетка 2 колонки × 3 строки (13 px, `muted`), значок 14 px слева от подписи, все обозначения:
   - Месячные — круг с заливкой `btnBg`;
   - Месячные (прогноз) — круг с пунктирной обводкой `rose`;
   - Фертильное окно — круг `violetSoft` с пунктирной обводкой `violetMid`;
   - Овуляция — иконка короны;
   - Сегодня — круг с обводкой `ink`;
   - Есть записи — точка `muted`.
5. Карточка выбранного дня (показывается под календарём, не всплывает; по умолчанию выбран сегодняшний день):
   «24 октября · 10-й день» + пилюля уровня («Высокая» `violetSoft`/`violetText`;
   «Средняя» `violetSoft`/`violetText`; «Низкая» `sageSoft`/`ink`), строка пояснения 14 px `muted`,
   две кнопки-пилюли высотой 44: «Симптомы», «Заметка» (фон `bg`, рамка `line`).
   Кнопки «Месячные» в карточке нет: нажатие на сегодняшний или прошедший день в сетке выбирает его и сразу
   открывает нижний лист «Месячные» (состав кнопок — specs/003-calendar-tap-actions); будущий день только
   выбирается. Даты не выделяются и не вызывают лупу/меню/синюю подсветку iOS.
6. Пометка 12 px `muted`: «Прогноз ориентировочный и не заменяет контрацепцию» (может быть в карточке дня).
7. Нижняя навигация.

## Экран «Сегодня» (макет C)

1. Шапка: «Пятница» (14, `muted`) / «23 октября» (24, 800).
2. Крупная карточка `surface`, radius 28: название фазы (14, `muted`) — «Менструальная фаза» (дни месячных),
   «Фолликулярная фаза» (после месячных до овуляции), «Овуляция» (день овуляции), «Лютеиновая фаза»
   (после овуляции до следующих месячных); при задержке и без данных подпись не показывается.
   Ниже «9-й день цикла» (34, 800),
   справа пилюля «из 28» (`roseSoft`/`roseText`). Внутри блок `violetSoft` radius 20: «Вероятность зачатия»,
   уровень крупно (30, 800, `violetText`), пояснение 14. Под блоком — пометка о прогнозе 12 px `muted`.
3. Полоска недели Пн–Вс: 7 плиток высотой 76, radius 20 (`surface` + рамка `line`), день недели 12/700,
   число 18/800, точка 8 px по уровню: месячные `rose`, низкая `sage`, средняя `violetMid`, высокая `violetDeep`.
   Сегодняшняя плитка инвертирована: фон `ink`, текст `bg`.
   Плитки сегодняшнего и прошедших дней нажимаются и открывают лист «Месячные» для своего дня; будущие
   плитки не нажимаются. Сводка выше всегда о сегодняшнем дне.
4. Карточка «Ближайшие даты» — строки с разделителями `line`: точка `violetMid` + Фертильное окно (даты, «завтра»);
   иконка короны + Овуляция (дата, «через N дн.»); точка `rose` + Месячные («≈ дата», «через N дн.»).
5. Две кнопки-пилюли высотой 52: «Симптомы», «Заметка» (`surface` + рамка) — для сегодняшнего дня.
   «Месячные» открываются нажатием на плитку дня в полоске недели (п. 3).
6. Нижняя навигация.

## Нижняя навигация

Фон `surface`, верхняя граница 1 px `line`, отступы 8/12/20. Четыре равные вкладки (иконка 22 + подпись 12):
Сегодня (круг с точкой) · Календарь (календарик) · Статистика (три столбика) · Настройки (два ползунка).
Активная — `roseText`, 800; остальные — `muted`, 600.

## Главная кнопка действия

Высота 54, radius 27, фон `btnBg`, текст `btnInk` 17/800, иконка капли слева.
