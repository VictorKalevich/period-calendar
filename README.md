# Календарь цикла

Офлайн-приложение для iPhone: календарь месяца, отметки месячных, симптомов, настроения и заметок,
прогноз месячных, овуляции и фертильного окна, вероятность зачатия, статистика и push-напоминания.

> Прогноз ориентировочный и не заменяет контрацепцию и консультацию врача.

## Приватность

- Все данные цикла — отметки, симптомы, настроение, заметки и настройки — хранятся **только на телефоне**
  (IndexedDB). Аккаунтов, аналитики и сторонних скриптов нет.
- Если включить напоминания, на push-сервер (Cloudflare Worker) уходят только: push-подписка браузера,
  даты/время и тексты ближайших напоминаний, а для авторизации — случайный идентификатор устройства
  и SHA-256 хэш его секретного токена. Отметки, симптомы и заметки сервер не получает.

## Установка на iPhone

1. Откройте адрес приложения в Safari (iOS 16.4 или новее).
2. «Поделиться» → «На экран „Домой“».
3. Запускайте с иконки — приложение работает без интернета.
4. Для напоминаний: «Настройки» → «Включить напоминания» → разрешить уведомления.

## Резервная копия

Данные есть только на этом телефоне. «Настройки» → «Экспорт» сохраняет JSON-файл (например, в «Файлы»),
«Импорт» восстанавливает его на новом телефоне. Формат — `specs/001-cycle-calendar/contracts/backup-format.md`.

## Разработка

```bash
npm ci
npm test                       # доменная логика, хранилище, миграции, резервная копия, контраст темы
npm run dev                    # http://localhost:5173/period-calendar/
npm run build && npm run preview

npm ci --prefix worker
npm test --prefix worker       # Web Push (RFC 8291/8292), API и cron воркера
```

- `src/domain` — чистые функции прогноза, разрабатываются тестами вперёд.
- `src/storage` — Dexie (IndexedDB) с версиями схемы; чек-лист новой версии — `src/storage/migrations/README.md`.
- `src/ui` — React-экраны по макетам `docs/design/design.md`.
- `worker/` — Cloudflare Worker для push-напоминаний.

Деплой приложения — GitHub Actions при push в `main` (тесты → сборка → GitHub Pages).
Настройка push и сценарии проверки — `specs/001-cycle-calendar/quickstart.md`.

Принципы проекта — `.specify/memory/constitution.md`. Шрифт Nunito распространяется по лицензии SIL OFL 1.1
(`src/ui/fonts/OFL.txt`).
