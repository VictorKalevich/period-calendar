# Контракт: тест архитектуры и карта

Внешних интерфейсов шаг не добавляет. Контракт — то, на что опираются разработчики и агенты: что
проверяет `src/architecture.test.ts`, что он сообщает и как устроена карта `docs/architecture.md`.

## Что проверяется

| Проверка | Красный, если |
|----------|---------------|
| Распознавание импортов (образцы) | одна из форм R2 не найдена или найден импорт в комментарии/строке |
| Отнесение к слою и пакету (образцы) | путь или пакет отнесён не туда (R4) |
| Правила (образцы) | доменный файл с `react`, `react-dom`, `dexie`, `../storage`, `../ui`, `../push`, `../hooks`, `../report`, `../pwa` не даёт нарушения; разрешённый импорт даёт |
| Каждый исходный файл | у файла нет слоя или есть нарушение — список строк по формату `data-model.md` |
| Каждый слой | в слое нет ни одного файла (опечатка в пути таблицы) |
| Каждое исключение | файл не импортирует `target` |
| Часы в домене | текст доменного файла совпадает с `/new\s+Date\(\s*\)\|Date\.now\(/` |
| Карта | нет файла; > 120 строк; нет раздела; несуществующий путь; слои не совпадают с таблицей |

Тесты (`*.test.ts`, `*.test.tsx`) не проверяются: им можно импортировать что угодно.

## Как добавить правило или исключение

- Новый каталог или файл верхнего уровня `src` — строка в таблице слоёв теста и в таблице «Слои» карты
  (тест сверяет обе).
- Новая зависимость слоя — сначала строка в «Целевых правилах слоёв» и обоснование в плане фичи, затем
  `layers`/`packages` в таблице.
- Единичный импорт против правил — исключение `{ file, target, reason }` с причиной; распознавание не
  ослабляется.

## Сообщение

```text
src/storage/__violation.ts:1: '../ui/App' — слой storage не может импортировать слой ui
src/ui/__violation.ts:1: 'date-fns' — слою ui не разрешён пакет date-fns
src/extra.ts: файл вне таблицы слоёв — отнесите его к слою
src/push/sync.ts: исключение dexie больше не нужно — удалите его
```

## Карта архитектуры

```text
# Архитектура
<1–2 строки: что это и где точные правила>
## Слои
| Слой | Может импортировать | Зачем |   ← первая ячейка — путь в обратных кавычках
## Пути данных
## Правила корректности данных
## Чек-листы
### Добавить настройку
### Добавить отметку дня
### Добавить вид напоминания
```

Не больше 120 строк. Пути — без номеров строк. Подробности, которые устаревают быстро (номера строк,
тексты интерфейса), в карту не пишутся: она ссылается на файлы.
