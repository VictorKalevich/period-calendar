# Quickstart: проверка фичи 011

## Автоматически

```powershell
npm.cmd test      # report.test.ts (содержание), pdf.test.ts (структура файла)
npm.cmd run build
```

## Вручную (`npm.cmd run dev`, окно 390×844, светлая и тёмная тема)

1. Без отметок → «Статистика»: карточки «Отчёт для врача» нет.
2. Импортировать историю (резервная копия или текстовый файл) → «Статистика» → «Отчёт для врача» →
   «Создать отчёт» → лист «Отчёт готов» с «Поделиться» (на iPhone) и «Сохранить на устройство».
3. «Сохранить на устройство» → PDF открывается: период 12 месяцев, сводка совпадает со «Статистикой»,
   график и таблица циклов, колонтитул «стр. N из M».
4. Включить «Самочувствие», «Интенсивность», «Настроение», отметить несколько дней → новый отчёт
   содержит таблицы самочувствия (со степенями) и настроений; заметок и отметок секса нет.
5. Одна отметка месячных → отчёт: средние «—», «Пока нет завершённых циклов», «ориентировочно».
6. На iPhone: «Поделиться» → системное меню с PDF; «Сохранить в Файлы» работает.
