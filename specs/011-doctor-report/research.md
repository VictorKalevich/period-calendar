# Research: Отчёт для врача в PDF

## R1. Как сделать PDF без библиотек

**Decision**: страницы A4 рисуются на `<canvas>` (2 px на пункт: 1191×1684), кодируются
`canvas.toBlob('image/jpeg', 0.92)` и собираются в PDF 1.4: на страницу — объект изображения
(`/Filter /DCTDecode`, `/DeviceRGB`, 8 бит), поток содержимого `q 595.28 0 0 841.89 0 0 cm /Im0 Do Q`,
`/MediaBox [0 0 595.28 841.89]`; каталог, дерево страниц, `/Info` с `/Title` (UTF-16BE с BOM — кириллица),
таблица xref с 10-значными смещениями, trailer. JPEG вкладывается как есть, без перекодирования.

**Rationale**: шрифт Nunito уже в бандле и работает на холсте; встроить его в «настоящий» PDF-текст
нельзя без TTF-файла и библиотеки (woff2 → TTF требует распаковки brotli и восстановления таблиц). Сборщик
из JPEG — несколько десятков строк, легко тестируется, файл открывают все просмотрщики. Размер — около
150–300 КБ на страницу.

**Alternatives considered**: jsPDF + TTF Nunito с кириллицей (≈ 350 КБ кода + ≈ 200 КБ шрифта, новая
зависимость); `window.print()` → «Сохранить в PDF» — на iOS PWA печать неудобна и нельзя сразу
«Поделиться» файлом; PNG вместо JPEG — нужен Flate и предиктор, сложнее и тяжелее.

## R2. Поделиться и сохранить

**Decision**: PDF создаётся по «Создать отчёт», затем открывается лист с кнопками. «Поделиться» —
`navigator.share({ files: [file] })` прямо в обработчике нажатия (Safari требует свежего жеста — поэтому
файл готовится заранее, до показа кнопки); кнопка видна, только если `navigator.canShare({ files })`.
«Сохранить на устройство» — скачивание `<a download>` с blob-URL (iOS показывает просмотр с «Сохранить
в Файлы»). Общая функция `shareOrDownload` переносится из `BackupSection` в `src/ui/components/share.ts`.

## R3. Содержание и совпадение со «Статистикой»

**Decision**: средние — `averageCycleLength`/`averagePeriodLength` по всем циклам (как «Статистика» и
прогноз, последние 6 без выбросов); период отчёта — циклы с началом в `[today − 12 месяцев, today]`;
разброс — min–max длины завершённых невыбросов за период; ожидаемые следующие — `todaySummary().nextPeriod`
из `buildForecast` (при задержке — «Задержка N дн.»); низкая уверенность — `forecast.confidence === 'low'`.
Самочувствие и настроения — дни записей в периоде `[from, today]`; показываются по переключателям (как
везде в приложении: выключенное скрыто). Степени — счёт дней по `intensity`, «без степени» не выводится.

## R4. Вёрстка

**Decision**: поля 40 pt; заголовок 20/800; подзаголовок 10/600 `muted`; сводка — 4 плитки 2×2
(`bg`-фон, подпись 9/700 `muted`, значение 16/800 `ink`, пояснение 8.5/600 `muted`); график — столбцы
`btnBg` (выбросы — `rose` 45 %), пунктир средней `violet`, подписи дат «08.11» под столбцами; таблицы —
шапка 9/800 `muted`, строки 10/600 `ink`, разделители `line`; колонтитул 8/600 `muted`. Перенос — по
строкам таблиц, шапка таблицы повторяется. Палитра — светлая тема design.md (печать).
