# Quickstart: проверка фичи 012

```powershell
npm.cmd test
npm.cmd run build
```

Вручную (`npm.cmd run dev`, 390×844, светлая и тёмная тема; в Настройках включены все записи дня):

1. Нажать завтрашний день → в диалоге только «Заметки» и «Отмена». Выключить «Заметки» → диалог не открывается.
2. Вчера: отметить самочувствие → снова нажать вчера → «Самочувствие» выделено, «Настроение»/«Заметки» — нет.
3. Открыть «Самочувствие», «Настроение», «Заметку», диалог дня → ни один элемент не обведён.
4. «Интенсивность» включена: отметить «Головная боль» → выбрано «средне»; нажать «средне» → остаётся;
   «сильно» → «Готово» → «Головная боль · сильно».
5. Старая запись без степени (отмечена при выключенной интенсивности) → включить интенсивность → лист
   показывает «средне».
6. Заметка: написать → открыть снова → корзина → «Отмена» → текст на месте; корзина → «Удалить» →
   заметки нет, самочувствие дня на месте.
