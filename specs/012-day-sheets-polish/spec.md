# Feature Specification: Доработки диалога дня и листов записей

**Feature Branch**: `012-day-sheets-polish`

**Created**: 2026-11-11

**Status**: Draft

**Input**: User description: "Настроение и самочувствие нельзя ставить в будущих днях — только прошлое и
сегодня (как отметку секса); заметки в будущем — можно. В заметках — отдельная кнопка-значок корзины;
по нажатию — предупреждение, что заметка будет удалена, и подтверждение. Когда открываются листы
самочувствия и настроения, первый элемент обведён, будто выделен, — такого состояния быть не должно:
только нажата / не нажата, для всех подобных элементов. Интенсивность по умолчанию — «средне», в том
числе в старых записях, где интенсивность не отмечалась. Если у дня есть записи (самочувствие,
настроение, заметки), соответствующие кнопки в диалоге дня выделены (чуть другой фон и цвет текста или
обводка) — это правило для всех подобных пунктов и в дальнейшем."

## Clarifications

### Session 2026-11-11

Решения исполнителя («делай как считаешь нужным» — общее правило владельца):

- Q: Что с уже сделанными записями самочувствия/настроения на будущих датах? → A: Не удаляются; видны в
  карточке дня; редактировать их можно, когда день наступит.
- Q: Можно ли снять степень интенсивности? → A: Нет: у отмеченного пункта всегда ровно одна степень
  (по умолчанию «средне»); снятие пункта убирает и степень.
- Q: Карточка дня и отчёт для врача для старых записей без степени? → A: Показывают только сохранённую
  степень. «Средне» предлагается в листе и сохраняется по «Готово».
- Q: Выделять ли кнопку отметки секса? → A: Нет: она уже меняет надпись («Убрать отметку секса»);
  правило касается кнопок, открывающих листы записей.
- Q: Фокус с клавиатуры? → A: Обводка остаётся только для навигации с внешней клавиатуры (Tab); при
  открытии листа и нажатиях пальцем её нет.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Записи о самочувствии и настроении — только за прошедшие дни (Priority: P1)

Будущий день: в диалоге нет «Самочувствия» и «Настроения»; «Заметки» есть.

**Independent Test**: включить всё; нажать завтрашний день — в диалоге только «Заметки» и «Отмена»;
выключить «Заметки» — диалог для будущего дня не открывается.

**Acceptance Scenarios**:

1. **Given** включены «Самочувствие», «Настроение», «Заметки», **When** нажат будущий день, **Then** в
   диалоге только «Заметки».
2. **Given** «Заметки» выключены, **When** нажат будущий день, **Then** диалог не открывается.
3. **Given** сегодня или прошлый день, **Then** «Самочувствие» и «Настроение» доступны, как раньше.

---

### User Story 2 - Видно, где уже есть записи (Priority: P1)

В диалоге дня кнопки «Самочувствие», «Настроение», «Заметки» выделены, если за этот день уже есть
такая запись.

**Independent Test**: отметить самочувствие за вчера — в диалоге вчерашнего дня «Самочувствие» выделено,
«Настроение» и «Заметки» — нет.

**Acceptance Scenarios**:

1. **Given** у дня есть самочувствие и заметка, **When** открыт диалог, **Then** «Самочувствие» и
   «Заметки» выделены, «Настроение» — нет.
2. **Given** записей нет, **Then** ни одна кнопка не выделена.
3. **Given** экранный диктор, **Then** выделенная кнопка читается с пометкой «есть записи».

---

### User Story 3 - Удаление заметки с подтверждением (Priority: P2)

В редакторе заметки — кнопка-значок корзины. Нажатие показывает «Удалить заметку?» с текстом «Заметка
за 24 октября будет удалена.» и кнопками «Удалить» и «Отмена».

**Independent Test**: написать заметку, открыть снова → корзина → «Удалить» → заметки нет; другая
отметка этого дня (например, самочувствие) на месте.

**Acceptance Scenarios**:

1. **Given** у дня есть сохранённая заметка, **When** открыт редактор, **Then** видна кнопка-корзина.
2. **Given** заметки нет, **Then** корзины нет.
3. **Given** нажата корзина, **When** «Отмена», **Then** редактор снова виден, текст не изменён.
4. **Given** нажата корзина, **When** «Удалить», **Then** заметка удалена, остальные записи дня
   сохранены, лист закрыт.

---

### User Story 4 - Без «выделенного» первого элемента (Priority: P2)

При открытии любого листа ни один элемент не обведён. У кнопок-чипов и сегментов два состояния:
нажата / не нажата.

**Independent Test**: открыть «Самочувствие», «Настроение», «Заметку», диалог дня — обводки нет.

---

### User Story 5 - Интенсивность «средне» по умолчанию (Priority: P2)

При включённой интенсивности отмеченный пункт самочувствия сразу получает «средне». В старых записях без
степени при открытии листа выбрано «средне».

**Independent Test**: отметить «Головная боль» — выбрано «средне»; нажать «средне» ещё раз — остаётся
выбранным; «сильно» → «Готово» → в карточке «Головная боль · сильно».

**Acceptance Scenarios**:

1. **Given** интенсивность включена, **When** отмечен пункт, **Then** у него выбрано «средне».
2. **Given** запись, сделанная при выключенной интенсивности, **When** лист открыт с включённой
   интенсивностью, **Then** у её пунктов выбрано «средне»; «Готово» сохраняет «средне».
3. **Given** выбрана степень, **When** нажата та же степень, **Then** она остаётся выбранной.
4. **Given** интенсивность выключена, **When** отмечен новый пункт и нажато «Готово», **Then** степень не
   сохраняется; сохранённые степени других пунктов не меняются.

### Edge Cases

- Будущие записи самочувствия/настроения, сделанные до этой фичи, не удаляются (Clarifications).
- Отметка секса для будущих дней по-прежнему недоступна (009).
- Удаление заметки при пустой остальной записи удаляет запись дня целиком (как раньше).

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Диалог будущего дня MUST NOT содержать «Самочувствие» и «Настроение»; «Заметки» — по
  переключателю. Диалог будущего дня MUST открываться, только если включены «Заметки».
- **FR-002**: Записи самочувствия и настроения на будущих датах MUST NOT удаляться.
- **FR-003**: В диалоге дня кнопки «Самочувствие», «Настроение», «Заметки» MUST выделяться, если у дня
  есть запись этого типа: фон `violetSoft`, текст `violetText`, рамка `violetSoft` (как нажатый чип);
  для экранного диктора — пометка «есть записи». Правило распространяется на будущие кнопки записей.
- **FR-004**: Редактор заметки MUST содержать кнопку-значок корзины (44×44, подпись для диктора
  «Удалить заметку»), если у дня есть сохранённая заметка; нажатие MUST показывать подтверждение
  «Удалить заметку?» / «Заметка за {дата} будет удалена.» / «Удалить» / «Отмена». Прежняя текстовая
  кнопка «Удалить заметку» убирается.
- **FR-005**: При открытии любого нижнего листа ни один его элемент MUST NOT получать видимую обводку
  фокуса; обводка допустима только при навигации внешней клавиатурой.
- **FR-006**: При включённой интенсивности каждый отмеченный пункт самочувствия MUST иметь ровно одну
  степень; по умолчанию — «средне», в том числе для сохранённых пунктов без степени; повторное нажатие
  на выбранную степень её не снимает.
- **FR-007**: Правила (будущие дни, выделение, степень по умолчанию) MUST быть чистыми функциями с
  тестами, написанными до реализации.
- **FR-008**: `docs/design/design.md` и документы 004/009 MUST быть обновлены.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Для будущего дня в диалоге 0 кнопок самочувствия и настроения при любых настройках.
- **SC-002**: При открытии каждого из 5 листов (диалог дня, самочувствие, настроение, заметка, отчёт) —
  0 обведённых элементов.
- **SC-003**: В открытом редакторе удалить заметку — 2 нажатия (корзина → «Удалить»); одно нажатие
  ничего не удаляет.

## Assumptions

- Корзина — в правом верхнем углу листа заметки, на одной линии с заголовком.
- Формулировка пометки для диктора: «Самочувствие, есть записи».
