# Contract: тестовый push (дополнение к 001 contracts/push-worker-api.md)

## `POST /v1/clients/{clientId}/test`

Сразу отправляет на подписку клиента тестовое уведомление. Тело запроса не нужно.

- Авторизация: `Authorization: Bearer {token}` — тот же токен, что для `PUT`. Хэш сверяется с
  `tokenHash` записи; запрос с чужим токеном не меняет запись.
- Текст фиксирован на сервере: payload `{ "title": "Календарь цикла", "body": "Уведомления работают", "id": "test" }`.
- Ограничение: не чаще 1 раза в 60 с на клиента. Время последней попытки хранится в записи:
  `StoredRecord.lastTestAt` (ISO-8601). Попытка засчитывается до отправки.
- CORS: `Access-Control-Allow-Methods: PUT, DELETE, POST`.

| Ответ | Когда |
|-------|-------|
| `204` | push-сервис принял сообщение (2xx) |
| `400` | `clientId` не UUID |
| `401` | нет токена или он не совпадает |
| `404` | записи клиента нет |
| `410` | push-сервис ответил 404/410 — запись удалена, нужно подписаться заново |
| `429` | прошло меньше 60 с с прошлой попытки; заголовок `Retry-After: <секунды>` |
| `502` | push-сервис ответил другой ошибкой |
