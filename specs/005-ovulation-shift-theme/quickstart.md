# Quickstart: фича 005

| # | Сценарий | Ожидание | Требования |
|---|----------|----------|------------|
| 1 | Месячные с 1-го → календарь | Корона на 14-м, окно 9–14 | FR-003, FR-004 |
| 2 | Настройки → «Учитывать личный сдвиг овуляции» → +2 | Подсказка, счётчик «+2 дня» не сдвигает кнопки; корона на 16-м | FR-006, FR-007 |
| 3 | Выключить сдвиг | Корона на 14-м; после включения снова +2 | FR-007 |
| 4 | «Подробнее» при сдвиге +2 | Новый расчёт + строка «Учтён ваш личный сдвиг овуляции: +2 дня …» | FR-009 |
| 5 | Карточка дня | Дата, день цикла, фаза; нет вероятности | FR-010 |
| 6 | Светлая тема | Новые нежные розовые | FR-001 |
| 7 | Прокрутить страницу, открыть шит, водить пальцем по шиту и фону, закрыть | Страница не двигается, позиция после закрытия та же; длинный шит листается сам | FR-002 |
| 8 | Экспорт → импорт; импорт копии прежней версии | Сдвиг восстановлен / выключен, 0 | FR-008 |
