# Quickstart: проверка фичи 009

## Автоматически

```powershell
npm test          # домен (coerceDayEntry, видимость, диалог), миграции, открытие баз v1–v5, импорт копий
npm run build
```

Ключевые тесты: `src/domain/dayEntry.test.ts`, `src/domain/dayDialog.test.ts`,
`src/storage/migrations/migrations.test.ts`, `src/storage/upgrade-v2.test.ts` (базы v1–v5 с записями
дней → v6), `src/storage/backup.test.ts` (мягкий импорт), `src/storage/update.test.ts`.

## Вручную (`npm run dev`, окно 390×844, светлая и тёмная тема)

1. Свежая база (очистить данные сайта) → Настройки → «Записи дня»: «Самочувствие», «Настроение»,
   «Отметка секса», «Заметки» выключены; «Интенсивность самочувствия» не видна.
2. Включить «Отметка секса» → нажать вчерашний день → «Отметить секс» → сердечко у дня, «Секс» в
   легенде и карточке дня. Снова нажать → «Убрать отметку секса» → сердечка нет. Будущий день — кнопки
   нет. Выключить переключатель — сердечек и пункта легенды нет.
3. Включить «Настроение» → день → «Настроение» → выбрать «Спокойная», «Тревожная», «Игривая» →
   «Готово» → в карточке три пилюли, у дня точка.
4. Включить «Самочувствие» → появился переключатель «Интенсивность самочувствия» → включить → день →
   «Самочувствие» → «Головная боль» → «сильно» → «Готово» → «Головная боль · сильно». Выключить
   интенсивность → «Головная боль». Включить — степень на месте.
5. Перенос: в сборке `main` (до 009) отметить месячные и записи с настроением «Отличное» и «Спокойное»,
   затем открыть сборку 009 → месячные на месте, настроения «Радостная» и «Спокойная»; если до
   обновления «Самочувствие» было включено — «Настроение» включено.
6. Импорт копии с испорченными записями дней (неизвестные коды, `"mood": 5`, заметка-число) →
   подтверждение → все месячные восстановлены, испорченные отметки пустые.
7. Зоны нажатия сегментов степени и кнопок листов ≥ 44 px; сердечко различимо на днях месячных,
   фертильного окна и овуляции в обеих темах.
