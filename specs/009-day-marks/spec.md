# Feature Specification: Отметка секса, несколько настроений и интенсивность самочувствия

**Feature Branch**: `009-day-marks`

**Created**: 2026-11-11

**Status**: Draft

**Input**: User description: "По отзыву тестировщицы (переписка 25–26.10.2026). В Настройках —
переключатель «Отметка секса»: после включения день в календаре можно отметить сердечком. Настроение —
отдельным переключателем, можно выбрать несколько, список по её требованиям, без эмодзи. Интенсивность
симптомов (слабо / средне / сильно) — тоже переключателем. Всё новое у только что установивших
приложение выключено. Настроениям — коды, сопоставление старых значений по кодам, неподходящие
игнорировать. Главное — сохранность истории циклов: ошибки миграции, импорта и разбора ловятся,
приложение не падает, старая база имеет приоритет; настроения и другие отметки могут быть пустыми —
при ошибке сохраняются пустыми. Отметка «защищённый / незащищённый» и подсказка «сделать тест» —
позже, вместе с работой над воркером."

## Clarifications

### Session 2026-11-11

Решения владельца проекта («делай как считаешь нужным» по открытым вопросам):

- Q: Новые переключатели у тех, кто уже пользуется приложением? → A: «Отметка секса» и «Интенсивность
  самочувствия» выключены и после обновления. «Настроение» после обновления повторяет прежнее
  «Самочувствие»: раньше настроение было его частью, поэтому у кого оно было видно — остаётся видно.
- Q: Старое настроение «Отличное»? → A: Сопоставляется с «Радостная».
- Q: Отметка «защищённый / незащищённый»? → A: Не в этой фиче — нужна только для подсказки «сделать
  тест», которая отложена.

## Термины

- **Самочувствие** — физические отметки дня (боль, вздутие, усталость…). С этой фичи настроение в него
  не входит. Слово «Симптомы» в интерфейсе по-прежнему не используется (004 FR-003).
- **Настроение** — эмоции дня; можно выбрать несколько или ни одного.
- **Интенсивность** — «слабо», «средне» или «сильно» у отмеченного пункта самочувствия; может быть
  не выбрана.
- **Отметка секса** — факт за день («был»), без количества и подробностей. В календаре — сердечко.
- **Код** — постоянный идентификатор пункта (настроения, самочувствия, интенсивности), который хранится
  в данных и в резервной копии вместо подписи. Подписи можно менять, коды — нет.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Обновление без потерь и без падений (Priority: P1)

Пользовательница обновляет приложение или восстанавливает резервную копию. Все месячные, записи дней и
настройки на месте, прежнее настроение превратилось в одно выбранное из нового списка. Если какая-то
часть данных повреждена или непонятна, приложение не падает: непонятные отметки дня становятся
пустыми, а история циклов не теряется.

**Why this priority**: история циклов — главное в приложении; новая форма записей дня не должна её
поставить под угрозу.

**Independent Test**: открыть новой сборкой базу каждой прежней версии с месячными, записями дней
(с настроением, неизвестными и испорченными значениями) и настройками — всё читается, месячные
совпадают один в один, приложение работает. Импортировать копию с испорченными записями дней —
месячные восстановлены полностью.

**Acceptance Scenarios**:

1. **Given** база прежней версии с месячными и записями дней, **When** открыта новая сборка, **Then**
   все месячные и записи на месте, у записи с настроением «Спокойное» выбрано «Спокойная», с
   «Отличное» — «Радостная».
2. **Given** запись дня с неизвестным или испорченным настроением, самочувствием или заметкой, **When**
   новая сборка её читает или переносит, **Then** испорченная часть становится пустой, остальное
   сохраняется, запись не удаляется, приложение не падает.
3. **Given** резервная копия с испорченными записями дней, но корректными месячными, **When** импорт,
   **Then** все месячные восстановлены, корректные части записей восстановлены, испорченные — пустые.
4. **Given** резервная копия с испорченными месячными, **When** импорт, **Then** импорт отклонён с
   понятным сообщением, текущие данные на устройстве не изменены.
5. **Given** резервная копия с испорченным значением настройки, **When** импорт, **Then** для этой
   настройки остаётся текущее значение на устройстве, остальное импортируется.
6. **Given** свежая установка, **When** открыты Настройки, **Then** «Отметка секса», «Настроение» и
   «Интенсивность самочувствия» выключены.

### User Story 2 - Несколько настроений (Priority: P1)

В Настройках включено «Настроение». В диалоге дня есть кнопка «Настроение»; она открывает список из
20 настроений без эмодзи, можно выбрать несколько или снять все. Выбранные видны в карточке дня.

**Why this priority**: тестировщица чаще всего чувствует несколько эмоций одновременно — одно
настроение не отражает день.

**Independent Test**: включить «Настроение», выбрать «Спокойная», «Тревожная» и «Игривая» — в карточке
дня три пилюли; снять все — в карточке ничего; выключить переключатель — настроение
скрыто, включить — снова видно.

**Acceptance Scenarios**:

1. **Given** «Настроение» включено, **When** нажат день, **Then** в диалоге есть «Настроение».
2. **Given** открыт выбор настроения, **When** отмечены три пункта и нажато «Готово», **Then** в
   карточке дня — три настроения в порядке списка.
3. **Given** «Настроение» выключено, **When** у дня есть настроения, **Then** нет кнопки в диалоге,
   настроения нет в карточке и оно не влияет на точку «Есть записи»; записи не удалены.
4. **Given** «Самочувствие» включено, а «Настроение» выключено, **When** открыт выбор самочувствия,
   **Then** в нём нет настроений.

### User Story 3 - Отметка секса сердечком (Priority: P2)

В Настройках включена «Отметка секса». В диалоге сегодняшнего или прошлого дня есть кнопка
«Отметить секс»; одно нажатие ставит отметку, в календаре у дня появляется сердечко. Повторно — «Убрать
отметку секса».

**Why this priority**: просьба тестировщицы; без переключателя функция никому не мешает.

**Independent Test**: включить переключатель, отметить вчерашний день — сердечко в календаре, в
карточке дня и пункт «Секс» в легенде; убрать — сердечка нет; выключить переключатель — сердечки и
кнопка скрыты, отметки не удалены.

**Acceptance Scenarios**:

1. **Given** «Отметка секса» включена, **When** нажат сегодняшний или прошлый день без отметки,
   **Then** в диалоге есть «Отметить секс»; нажатие ставит отметку и закрывает диалог.
2. **Given** день с отметкой, **When** нажат, **Then** в диалоге «Убрать отметку секса»; нажатие
   снимает отметку.
3. **Given** будущий день, **When** нажат, **Then** кнопки отметки секса нет; если других записей не
   включено, диалог не открывается (как в 004).
4. **Given** «Отметка секса» выключена, **When** у дней есть отметки, **Then** сердечек нет в
   календаре, карточке и легенде; кнопки в диалоге нет; отметки не удалены.
5. **Given** день, где отмечен только секс, **When** отметка снята, **Then** запись дня не остаётся
   пустой «пустышкой» (как пустая запись в 001).

### User Story 4 - Интенсивность самочувствия (Priority: P3)

В Настройках включены «Самочувствие» и «Интенсивность самочувствия». В выборе самочувствия у каждого
отмеченного пункта можно выбрать «слабо», «средне» или «сильно» (или ничего). В карточке дня —
«Головная боль · сильно».

**Why this priority**: уточняет уже существующие отметки; нужна для будущего отчёта врачу.

**Independent Test**: отметить «Головная боль» и «Вздутие», у первой выбрать «сильно» — в карточке
«Головная боль · сильно» и «Вздутие»; выключить интенсивность — в карточке «Головная боль» без
степени, данные сохранены.

**Acceptance Scenarios**:

1. **Given** «Интенсивность» включена, **When** в выборе самочувствия отмечен пункт, **Then** под
   списком у этого пункта три варианта: «слабо», «средне», «сильно»; ни один не выбран.
2. **Given** выбрана степень, **When** нажата та же степень ещё раз, **Then** степень снята.
3. **Given** у пункта есть степень, **When** сам пункт снят, **Then** его степень тоже удаляется.
4. **Given** «Интенсивность» выключена, **When** у пунктов есть степени, **Then** степени не
   показываются и не выбираются, но не удаляются.
5. **Given** «Самочувствие» выключено, **When** открыты Настройки, **Then** переключатель
   «Интенсивность самочувствия» не показан (его значение сохраняется).

### Edge Cases

- Запись дня, где нет ни самочувствия, ни настроений, ни отметки секса, ни заметки, не хранится.
- Повторяющиеся коды в одной записи схлопываются; порядок настроений и самочувствия — порядок списка.
- Степень у пункта, который не отмечен, отбрасывается.
- Старая сборка (откат релиза) может пересохранить день без новых полей — новые отметки этого дня
  пропадут; новая сборка такую запись читает без ошибок. Откатываться после этой фичи не рекомендуется.
- Резервная копия новой версии в старом приложении не импортируется («создана более новой версией»).
- Отметки секса, настроения и степени, как и вся запись дня, не покидают устройство (Конституция I) и
  не попадают в напоминания.

## Requirements *(mandatory)*

### Functional Requirements

**Сохранность и устойчивость**

- **FR-001**: Обновление MUST сохранять все месячные, записи дней, настройки и состояние push без
  изменений, кроме описанного переноса настроения и новых настроек.
- **FR-002**: Прежнее одно настроение MUST переноситься в набор из одного настроения по таблице кодов
  (calm→«Спокойная», sensitive→«Чувствительная», irritable→«Раздражённая», sad→«Грустная»,
  anxious→«Тревожная», great→«Радостная»); неизвестные коды MUST игнорироваться.
- **FR-003**: Перенос и чтение записей дня MUST NOT завершаться ошибкой: нераспознанные или
  испорченные части записи (настроения, самочувствие, степени, отметка секса, заметка) MUST становиться
  пустыми, запись MUST NOT удаляться, если у неё есть дата. Заметка длиннее 1000 символов обрезается до
  1000 (текст пользовательницы не выбрасывается).
- **FR-004**: Ошибка переноса или чтения записей дня MUST NOT мешать открытию приложения и работе с
  месячными.
- **FR-005**: Импорт резервной копии: месячные проверяются строго, как раньше; при ошибке в месячных
  импорт MUST быть отклонён, текущие данные MUST остаться без изменений. Записи дней MUST
  импортироваться мягко по правилу FR-003; запись без корректной даты пропускается; повтор даты —
  берётся первая. Испорченное значение настройки MUST заменяться текущим значением на устройстве.
- **FR-006**: Любая непредвиденная ошибка разбора файла импорта MUST перехватываться и показываться
  сообщением; данные на устройстве MUST остаться без изменений.

**Настройки**

- **FR-007**: Карточка «Записи дня» MUST содержать переключатели «Самочувствие», «Интенсивность
  самочувствия» (только когда «Самочувствие» включено), «Настроение», «Отметка секса», «Заметки».
- **FR-008**: При свежей установке «Настроение», «Интенсивность самочувствия» и «Отметка секса» MUST
  быть выключены. При обновлении и импорте копии прежней версии: «Настроение» = прежнее
  «Самочувствие», «Интенсивность самочувствия» и «Отметка секса» — выключены.
- **FR-009**: Выключение любого переключателя MUST NOT удалять данные; скрытые данные MUST входить в
  резервную копию.

**Настроение**

- **FR-010**: Список настроений (порядок показа, у каждого — код): Радостная, Весёлая, Довольная,
  В восторге, Воодушевлённая, Энергичная, Игривая, Спокойная, Нежная, Уверенная, Благодарная,
  Чувствительная, Грустная, Тревожная, Раздражённая, Злая, Одинокая, Перегруженная, Безразличная,
  Настроение меняется. Без эмодзи.
- **FR-011**: Можно выбрать любое число настроений, включая ни одного.
- **FR-012**: Диалог дня MUST содержать кнопку «Настроение», если переключатель включён; она открывает
  выбор настроения для этой даты. Выбор самочувствия MUST NOT содержать настроения.
- **FR-013**: Карточка дня MUST показывать выбранные настроения, если «Настроение» включено.

**Отметка секса**

- **FR-014**: Если «Отметка секса» включена, диалог сегодняшнего или прошлого дня MUST содержать
  кнопку «Отметить секс» (или «Убрать отметку секса», если отметка есть); нажатие MUST переключать
  отметку и закрывать диалог. Для будущего дня кнопки нет.
- **FR-015**: Если «Отметка секса» включена, день с отметкой MUST показывать в календаре сердечко,
  карточка дня — пометку «Секс», легенда — пункт «Секс». Иначе ничего из этого не показывается.

**Интенсивность**

- **FR-016**: Если включены «Самочувствие» и «Интенсивность самочувствия», для каждого отмеченного
  пункта самочувствия MUST быть доступен выбор одной степени из «слабо», «средне», «сильно» или
  никакой; повторное нажатие на выбранную степень снимает её.
- **FR-017**: Карточка дня MUST показывать степень рядом с пунктом («Головная боль · сильно»), только
  если интенсивность включена.

**Общее**

- **FR-018**: Точка «Есть записи» MUST учитывать включённые типы: самочувствие, настроение, заметки.
  Отметка секса показывается своим сердечком и в точке не учитывается.
- **FR-019**: Порядок кнопок диалога дня: кнопки месячных (003), «Отметить секс»/«Убрать отметку
  секса», «Самочувствие», «Настроение», «Заметки», «Отмена». Будущий день — диалог открывается, только
  если включены «Самочувствие», «Настроение» или «Заметки».
- **FR-020**: Правила видимости, состава диалога, переноса и мягкого разбора записей MUST быть чистыми
  функциями с тестами, написанными до реализации (Конституция IV).
- **FR-021**: Макеты (`docs/design/design.md`), документы 001/004 (модель данных, формат копии) и
  quickstart MUST быть обновлены.

### Key Entities

- **Запись дня** — дата; набор кодов самочувствия; степени для отмеченных кодов самочувствия
  (необязательно); набор кодов настроения (вместо одного настроения); отметка секса (да/нет); заметка.
- **Настройки** — добавляются переключатели «Настроение», «Интенсивность самочувствия», «Отметка
  секса» (да/нет).
- **Справочники** — коды и подписи самочувствия, настроений, степеней; таблица перевода старых кодов
  настроения.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: После обновления 100% месячных и 100% записей дней прежней версии на месте (проверяется
  тестами для баз каждой прежней версии).
- **SC-002**: Для испорченных записей и файлов (неизвестные коды, неверные типы, лишние поля, пустые
  значения) — 0 падений; история циклов из копии с испорченными записями дней восстанавливается на 100%.
- **SC-003**: Отметить секс — 2 нажатия (дата → «Отметить секс»).
- **SC-004**: Отметить три настроения — 6 нажатий (дата → «Настроение» → 3 пункта → «Готово»).
- **SC-005**: При свежей установке ни одна из трёх новых функций не видна, пока её не включили.

## Assumptions

- Название переключателя — «Интенсивность самочувствия» (слово «Симптомы» в интерфейсе не используется,
  004 FR-003); подпись под ним — «Слабо, средне или сильно — для каждой отметки самочувствия».
- Сердечко в календаре — небольшой значок в левом верхнем углу кружка дня (корона овуляции — в правом).
- Отметка секса доступна только для сегодняшнего и прошлых дней, как отметка месячных.
- Настроение, как и самочувствие, можно отмечать и для будущих дней (поведение 004 сохраняется).
- Отчёт для врача и подсказка о последних месячных — отдельные фичи (010, 011).

## Вне рамок

- Вечернее уведомление «Как ты сегодня?» — позже, вместе с воркером.
- Режимы «планирование беременности», «беременность», «после родов», «перименопауза».
