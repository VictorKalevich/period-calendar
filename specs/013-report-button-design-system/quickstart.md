# Quickstart: проверка фичи 013

```powershell
npm.cmd test        # в т.ч. design-system.test.ts и palette.test.ts
npm.cmd run build
```

Вручную (`npm.cmd run dev`, 390×844, светлая и тёмная тема):

1. «Статистика» с отметками → справа от заголовка «Отчёт» → «Создаю…» → лист «Отчёт готов» с пояснением,
   «Поделиться» (iPhone), «Сохранить на устройство», «Закрыть». Внизу карточки отчёта нет.
2. Без отметок → кнопки «Отчёт» нет.
3. Пройти экраны «Календарь» (диалог дня, листы), «Настройки», «Статистика»: вид как раньше; нажатые чипы,
   сегменты и кнопки записей с данными выглядят одинаково; кнопки листов одной высоты.
