# UI-контракт: аварийный экран и ошибка сохранения

Источник правды для вида — `docs/design/design.md` (раздел «Дизайн-система», компоненты «Аварийный
экран» и «Ошибка сохранения»). Здесь — разметка и тексты, которые проверяют тесты.

## Аварийный экран (`EmergencyScreen`)

```html
<section class="card settings-card" aria-labelledby="emergency-title">
  <h1 id="emergency-title" class="t-card-title settings-card__title">Что-то пошло не так</h1>
  <p class="t-body settings-card__text">Экран не удалось показать. Данные хранятся только на этом
    телефоне — сохраните резервную копию, затем перезагрузите приложение.</p>
  <button type="button" class="btn btn--primary">Экспорт данных</button>
  <button type="button" class="btn">Перезагрузить</button>
  <!-- только после неудачного экспорта: -->
  <p class="notice notice--error" role="alert">Не удалось создать резервную копию</p>
</section>
```

- Сбой экрана вкладки: карточка — единственное содержимое `main.app__screen`; `UpdateBanner` и
  `nav.tabbar` прежние и рабочие.
- Сбой оболочки (`EmergencyPage`): `div.app > main.app__screen > карточка`, навигации нет.
- «Экспорт данных» → `exportData()` = `shareOrDownload(await exportBackup())` — тот же файл
  `cycle-calendar-ГГГГ-ММ-ДД.json` и тот же способ, что «Экспорт» в Настройках.
- «Перезагрузить» → `location.reload()`.

## Ошибка сохранения (`SaveError`)

```html
<p class="notice notice--error" role="alert">Не удалось сохранить. Попробуйте ещё раз.</p>
```

Без ошибки компонент не рисует ничего — разметка обычного пути прежняя.

| Место | Позиция сообщения | Что остаётся после отказа |
|-------|-------------------|---------------------------|
| Лист «Настроение» | над «Готово» | лист открыт, выбранные настроения |
| Лист «Самочувствие» | над «Готово» | лист открыт, пункты и степени |
| Лист «Заметка» | над «Сохранить» | лист открыт, введённый текст |
| Подтверждение «Удалить заметку?» | над «Удалить» | подтверждение открыто |
| Диалог дня: кнопки месячных, «Отметить секс» | под кнопками месячных (место доменной ошибки) | диалог открыт |
| Подтверждение «Удалить месячные?» | над «Удалить» | подтверждение открыто |
| Карточка «Цикл» | последним элементом карточки | счётчик/переключатель — сохранённое значение |
| Карточка «Записи дня» | последним элементом карточки | переключатель — сохранённое значение |
| Карточка «Напоминания» | последним элементом карточки | переключатель — сохранённое значение |
| Строка версии (режим разработчика) | под строкой версии | режим не меняется |
| Подсказка «Как получить прогноз» | отдельным блоком под подсказкой | подсказка видна |

Ошибка экспорта в «Резервной копии» — существующий `notice notice--error` (`role="alert"`) под кнопками
с текстом «Не удалось создать резервную копию».
