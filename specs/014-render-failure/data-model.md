# Data Model: Сбой не оставляет пустой экран

Хранимые данные **не меняются**: `SCHEMA_VERSION`, таблицы `periods`, `days`, `kv`, форма записей,
формат резервной копии и запросов к воркеру — прежние (FR-019). Ниже — только состояния интерфейса
(в памяти, не сохраняются).

## Граница ошибок (`ErrorBoundary`)

| Поле | Тип | Смысл |
|------|-----|-------|
| `failed` | `boolean` | потомок бросил исключение при отрисовке или в эффекте |

Переходы: `false` → `true` при исключении (`getDerivedStateFromError`). Обратно — только новым экземпляром:
граница экрана получает `key={tab}`, поэтому смена вкладки создаёт новую границу; общая граница
приложения сбрасывается перезагрузкой.

## Реактивный запрос (`useLiveQuery`)

| Состояние | Возврат хука |
|-----------|--------------|
| нет данных | `undefined` (как раньше) |
| `{ value }` | `value` (как раньше; при смене `deps` держится до нового значения) |
| `{ error }` | бросает `error` при отрисовке → ближайшая граница |

Переходы: «нет данных» → `{ value }` при каждом `next`; любое → `{ error }` при `error` подписки
(с записью в консоль). Из `{ error }` выхода нет — компонент размонтируется границей.

## Ошибка сохранения (`useSaveError`)

| Поле | Тип | Смысл |
|------|-----|-------|
| `failed` | `boolean` | последняя запись через `save` не удалась |

Переходы: `save(write)` сначала ставит `false`, затем `true`, если `write` отклонён (`attempt` вернул
`false`); `reset()` → `false` — при открытии листа, его закрытии и переходе между видом листа и
подтверждением. `save` возвращает `true` при успехе — тогда обработчик делает то же, что раньше
(закрывает лист).

## Ошибка экспорта (аварийный экран, «Резервная копия»)

| Поле | Тип | Смысл |
|------|-----|-------|
| аварийный экран: `exportFailed` | `boolean` | `exportData()` вернул `false` |
| «Резервная копия»: `message` | `{ text, error } \| null` | существующее состояние; при неудаче — `{ text: 'Не удалось создать резервную копию', error: true }` |

Повторное нажатие «Экспорт данных» сбрасывает сообщение перед новой попыткой.
