# Quickstart: проверка «Сбой не оставляет пустой экран»

Команды — из PowerShell в папке проекта (из Git Bash с `cd /c/…` Vitest не стартует).

## Автоматически

```powershell
npm test          # не меньше 584 + новые; существующие проверки без изменений
npm run build
```

## Вручную (по желанию, `npm run dev`)

1. **Сбой экрана**: в DevTools → Application → IndexedDB → `cycle-calendar` → `periods` изменить у
   записи `start` на `"oops"` и открыть «Статистику» → аварийная карточка, навигация работает,
   «Календарь»/«Настройки» открываются (если сбой не задевает их). Вернуть запись (или удалить базу).
2. **Экспорт с аварийного экрана**: нажать «Экспорт данных» → файл `cycle-calendar-ГГГГ-ММ-ДД.json`, как
   из «Настроек» → «Экспорт».
3. **Темы**: переключить `prefers-color-scheme` (DevTools → Rendering) — карточка читаема в обеих темах,
   кнопки 52 px.
4. **Отказ записи** надёжно воспроизводится только подменой записи — его проверяют тесты из таблицы выше.
