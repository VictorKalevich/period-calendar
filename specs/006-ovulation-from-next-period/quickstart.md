# Quickstart: проверка фичи 006

## Автоматически

```bash
npm test          # прогноз в обоих режимах, напоминания, миграция v3 → v4, импорт копий
npm run build
```

Сценарии тестов — [contracts/ovulation-mode.md](./contracts/ovulation-mode.md).

## Вручную (`npm run dev`, узкое окно ~390 px, светлая и тёмная темы)

1. **Настройки → «Записи дня»**: только «Самочувствие» и «Заметки».
2. **Настройки → «Цикл»**: «Длина цикла…», «Длина месячных…», «Учитывать личный сдвиг овуляции»,
   «Считать от следующей менструации» с описанием. Включить сдвиг — между ними появляются подсказка
   и счётчик; второй переключатель остаётся виден.
3. Отметить месячные 1-го числа прошлого месяца и 1-го текущего (≈ 30–31 день). Выключенный режим —
   корона на 14-й день прошлого цикла; включить режим — корона за 14 дней до 1-го текущего месяца,
   окно и фазы в карточке дня следуют за ней без перезапуска.
4. Сдвиг +2 при включённом режиме — корона на 2 дня позже.
5. «Подробнее» — описан включённый способ; при сдвиге ≠ 0 — строка о сдвиге в обоих режимах.
6. Экспорт копии → импорт: переключатель сохраняется. Импорт копии прежней версии — выключен.
7. Обновление со сборки `main` (схема v3) — данные на месте, переключатель выключен.
