# Quickstart: Нажатие на дату и умные действия «Месячные»

Запуск — как в [001 quickstart](../001-cycle-calendar/quickstart.md) (`npm test`, `npm run build`,
`npm run preview`). Правила кнопок — [data-model.md](./data-model.md), тест-кейсы —
[contracts/period-actions.md](./contracts/period-actions.md).

| # | Сценарий | Ожидание | Требования |
|---|----------|----------|------------|
| 1 | Долго удерживать дату в календаре и в полоске недели на iPhone | Нет выделения, лупы, меню, синей подсветки | FR-001, SC-003 |
| 2 | Свежий запуск → нажать сегодня → «Начало месячных» | Месячные отмечены за 2 нажатия | FR-002, SC-001 |
| 3 | Нажать завтрашнюю дату | День выбран, диалога нет | FR-003 |
| 4 | Карточка дня и быстрые действия «Сегодня» | Только «Симптомы» и «Заметка» | FR-004, FR-005 |
| 5 | «Сегодня» → нажать вчерашний день в полоске | Открыт диалог «Месячные» для вчера; будущие плитки не нажимаются | FR-005 |
| 6 | Начало 5 дней назад без конца → нажать день начала | «Продлить месячные: …», «Конец месячных (один день)», «Убрать отметку» | FR-007 |
| 7 | Месячные закончились 4 дня назад → нажать сегодня | «Начало месячных», «Продлить месячные до …» | FR-008 |
| 8 | Месячные начались сегодня → нажать позавчера | «Начало месячных», «Установить как начало месячных» → месячные с позавчера | FR-010 |
| 9 | Внутри месячных, не начало → «Установить как начало» | Отметки до дня убраны, конец тот же | FR-009 |
