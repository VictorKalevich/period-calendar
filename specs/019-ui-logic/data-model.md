# Data Model: Решения — в чистых функциях, компоненты только рисуют

Хранимые данные не меняются: `SCHEMA_VERSION`, таблицы, `DayEntry`, `Settings`, `kv['push']` и формат
резервной копии прежние. Ниже — только значения в памяти, которые вводит шаг.

## SymptomSelection — состояние листа «Самочувствие»

| Поле | Тип | Правило |
|------|-----|---------|
| `symptoms` | `SymptomId[]` | Отмеченные пункты в порядке отметки; без повторов |
| `intensity` | `Partial<Record<SymptomId, Intensity>>` | Степени пунктов; при включённой интенсивности — ровно одна у каждого отмеченного |

Переходы (`showIntensity` — настройка «Интенсивность самочувствия»):

| Переход | Результат |
|---------|-----------|
| начальное (`entry`, `showIntensity = true`) | `symptoms = entry?.symptoms ?? []`; `intensity = withDefaultIntensity(symptoms, entry?.intensity ?? {})` — у пунктов без степени «средне», степени неотмеченных отброшены (012 FR-006) |
| начальное (`entry`, `showIntensity = false`) | `symptoms = entry?.symptoms ?? []`; `intensity = entry?.intensity ?? {}` без изменений |
| отметить `id` (не отмечен), `showIntensity = true` | `id` в конец `symptoms`; `intensity[id] = DEFAULT_INTENSITY` («средне») |
| отметить `id` (не отмечен), `showIntensity = false` | `id` в конец `symptoms`; `intensity` не меняется |
| снять `id` (отмечен) | `id` убран из `symptoms`; ключ `id` убран из `intensity` (009 US4, сц. 3); остальные степени целы |
| степень `id := level` | `intensity[id] = level`; повторный выбор той же степени её не снимает; `symptoms` не меняется |

Все переходы возвращают новое значение и не меняют вход. Сохранение листа пишет
`{ symptoms, intensity }` через `updateDayEntry`, как раньше.

## ImportFileKind — вид импортируемого файла

| Значение | Когда | Что делает «Резервная копия» |
|----------|-------|------------------------------|
| `'backup'` | текст после начальных пробельных символов (в том числе BOM) начинается с `{` | `parseBackup` → лист «Восстановить данные?» или ошибка разбора |
| `'cycle-text'` | не `'backup'`, и текст содержит «period start date:» без учёта регистра | `planTextImport` → лист «Добавить месячные?» или ошибка |
| `'unknown'` | иначе, в том числе пустой текст | сообщение «Файл не распознан» |

## ReminderToggleAction — действие после изменения переключателя напоминаний

Вход: новые значения `remindPeriod`, `remindOvulation`, `remindMissedPeriod`; `subscribed` (есть ли
подписка); `permission` (`'granted' | 'denied' | 'default' | 'unsupported'`).

| Условие (по порядку) | Действие |
|----------------------|----------|
| все три выключены | `'unsubscribe'` — `disableReminders()` |
| `!subscribed && permission !== 'denied'` | `'subscribe'` — включение (`enableReminders()` + `syncReminders()`) |
| иначе | `'none'` |

Действие выполняется только после успешного сохранения настройки; при отказе — сообщение в карточке,
подписка не трогается (014).

## Свойства `Toggle`

| Свойство | Тип | Разметка |
|----------|-----|----------|
| `label` | `string` | текст в `<span>` подписи |
| `hint` | `string?` | `<span class="t-small toggle__hint">` внутри подписи, после текста; нет — нет элемента |
| `checked` | `boolean` | `checked` у `input` |
| `disabled` | `boolean?` | `disabled` у `input`, если `true` |
| `describedBy` | `string?` | `aria-describedby` у `input`, если задан |
| `onChange` | `(checked: boolean) => void` | вызывается с новым состоянием |

Разметка: `<label class="toggle"><span>{label}[подсказка]</span><input type="checkbox" role="switch"
[checked] [disabled] [aria-describedby]/></label>`; порядок атрибутов прежний.

Десять мест:

| Экран / карточка | Подпись | Подсказка | Прочее |
|------------------|---------|-----------|--------|
| Настройки / «Цикл» | Учитывать личный сдвиг овуляции | — | — |
| Настройки / «Цикл» | Считать от следующей менструации | — | `describedBy="ovulation-mode-hint"` |
| Настройки / «Записи дня» | Самочувствие | — | — |
| Настройки / «Записи дня» | Интенсивность самочувствия (если «Самочувствие» включено) | Слабо, средне или сильно — для каждой отметки самочувствия | — |
| Настройки / «Записи дня» | Настроение | Можно выбрать несколько | — |
| Настройки / «Записи дня» | Отметка секса | Сердечко в календаре | — |
| Настройки / «Записи дня» | Заметки | — | — |
| «Напоминания» | За 2 дня до месячных | `PERIOD_REMINDER.body` | `disabled={busy}` |
| «Напоминания» | В день овуляции | `OVULATION_REMINDER.body` | `disabled={busy}` |
| «Напоминания» | Напоминать, если забыла отметить начало месячных | Придёт на 3-й день после ожидаемого начала месячных, если оно не отмечено | `disabled={busy}` |
