# Quickstart: Календарь цикла

Руководство по запуску и проверке фичи. Детали контрактов — в [contracts/](./contracts/),
модель данных — в [data-model.md](./data-model.md).

## Предварительные условия

- Node.js 24 LTS, npm.
- Аккаунт Cloudflare (бесплатный) и `wrangler` (dev-зависимость в `worker/`).
- Репозиторий на GitHub с включённым Pages (Source: GitHub Actions).
- iPhone с iOS 16.4+ для проверки установки и уведомлений.

## Локальный запуск приложения

```bash
npm ci
npm test              # доменные тесты, миграции, резервная копия
npm run dev           # http://localhost:5173/period-calendar/
npm run build && npm run preview   # проверка service worker и офлайна
```

Проверка на iPhone в локальной сети: `npm run preview -- --host`, открыть адрес в Safari
(push локально не работает — нужен HTTPS, проверяется после деплоя).

## Настройка push (один раз)

```bash
cd worker
npm ci
npx wrangler kv namespace create SUBS          # id вписать в wrangler.toml
node scripts/generate-vapid.mjs                # печатает публичный и приватный ключ
npx wrangler secret put VAPID_PRIVATE_KEY
# в wrangler.toml: VAPID_PUBLIC_KEY, VAPID_SUBJECT (mailto:), ALLOWED_ORIGIN
npm test                                       # векторы RFC 8291, валидация API
npx wrangler deploy
```

В GitHub → Settings → Secrets and variables → Actions → Variables: `VITE_VAPID_PUBLIC_KEY`,
`VITE_PUSH_API_URL`.

## Деплой

Push в `main` → workflow `deploy.yml`: тесты → сборка → GitHub Pages. Сборка не публикуется, если
тесты не прошли.

## Сценарии проверки

| # | Сценарий | Ожидаемый результат | Требования |
|---|----------|---------------------|------------|
| 1 | Открыть сайт в Safari → «Поделиться» → «На экран „Домой“», запустить с иконки | Полноэкранное приложение открывается на вкладке «Календарь» с приглашением отметить месячные | FR-001, US2-1 |
| 1a | Из свежего запуска отметить начало месячных сегодня, считая нажатия | Не больше 3 нажатий (день → «Месячные» → «Начало месячных») | SC-001 |
| 2 | Включить авиарежим, закрыть и открыть приложение | Приложение работает, данные на месте | FR-032, SC-003 |
| 3 | Календарь → день 4 дня назад → «Месячные» → «Начало» | Сплошная заливка для дней ≤ сегодня, пунктир дальше, появился прогноз, плашка «Сегодня 5-й день» | US1-3, US2-2 |
| 4 | Свайп влево/вправо и кнопки «‹ ›» | Месяц следует за пальцем, переключается плавно | FR-002, SC-002 |
