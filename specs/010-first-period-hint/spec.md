# Feature Specification: Подсказка «отметьте последние месячные» для новых пользовательниц

**Feature Branch**: `010-first-period-hint`

**Created**: 2026-11-11

**Status**: Draft

**Input**: User description: "Для тех, у кого не отмечено ни одного периода, вверху — подсказка, что для
прогнозирования нужно указать, когда начались последние месячные. Прятать подсказку сразу после их
указания или по крестику у этого блока." (По отзыву тестировщицы: она не поняла, что прошлые месячные
можно отметить прямо в календаре.)

## Clarifications

### Session 2026-11-11

- Q: Нужен ли переключатель в Настройках? → A: Нет: подсказка видна только тем, у кого нет ни одной
  отметки, и закрывается крестиком; с переключателем «выключено по умолчанию» новые пользовательницы
  её бы не увидели.
- Q: Если подсказку закрыли крестиком, а потом удалили все месячные? → A: Не показывать снова —
  крестик закрывает её навсегда на этом устройстве.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Новая пользовательница понимает, как получить прогноз (Priority: P1)

Приложение только установлено, месячных нет. Вверху экрана «Календарь» — карточка: прогноз появится,
когда отмечено начало последних месячных; для этого нужно нажать на этот день в календаре (прошедшие
дни тоже можно) и выбрать «Начало месячных». Историю из другого приложения можно загрузить в
Настройках. Как только месячные отмечены, карточка исчезает.

**Why this priority**: без первой отметки приложение бесполезно, а тестировщица не догадалась, что
прошлые даты можно отметить.

**Independent Test**: свежая установка — карточка видна; отметить начало месячных вчерашним днём —
карточка исчезла, появился прогноз.

**Acceptance Scenarios**:

1. **Given** нет ни одной отметки месячных и подсказку не закрывали, **When** открыт «Календарь»,
   **Then** вверху экрана видна подсказка.
2. **Given** подсказка видна, **When** отмечено начало месячных (в диалоге дня, импортом резервной
   копии или текстового файла), **Then** подсказка сразу исчезает.
3. **Given** есть хотя бы одна отметка, **When** открыт «Календарь», **Then** подсказки нет.
4. **Given** подсказку не закрывали, **When** удалены все месячные, **Then** подсказка снова видна.

---

### User Story 2 - Подсказку можно закрыть (Priority: P2)

Пользовательница не хочет видеть подсказку — нажимает крестик, и подсказка больше не появляется на
этом устройстве.

**Why this priority**: подсказка не должна мешать тем, кто разобрался сам или просто смотрит приложение.

**Independent Test**: свежая установка — крестик — подсказки нет; перезапуск приложения — подсказки нет.

**Acceptance Scenarios**:

1. **Given** подсказка видна, **When** нажат крестик, **Then** подсказка исчезает.
2. **Given** подсказку закрыли, **When** приложение перезапущено или удалены все месячные, **Then**
   подсказка не появляется.

### Edge Cases

- Отметка «закрыто» хранится только на устройстве и не входит в резервную копию (как режим
  разработчика): на новом телефоне после восстановления копии с месячными подсказки нет и так.
- Плашка над календарём «Отметьте начало последних месячных» остаётся: она — статус, подсказка — объяснение.
- Подсказка не меняет данные и прогноз.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Экран «Календарь» MUST показывать вверху, над шапкой месяца, подсказку, если нет ни одной
  отметки месячных и подсказку не закрывали на этом устройстве.
- **FR-002**: Подсказка MUST исчезать сразу, как только появилась хотя бы одна отметка месячных, любым
  способом.
- **FR-003**: Подсказка MUST иметь кнопку-крестик «Скрыть подсказку»; нажатие MUST скрывать подсказку
  навсегда на этом устройстве.
- **FR-004**: Если подсказку не закрывали, она MUST снова показываться, когда отметок месячных не осталось.
- **FR-005**: Отметка «закрыто» MUST храниться только на устройстве, MUST NOT входить в резервную
  копию; версия схемы хранения не меняется.
- **FR-006**: Текст подсказки: заголовок «Как получить прогноз»; «Отметьте, когда начались последние
  месячные: нажмите на этот день в календаре — прошедшие дни тоже можно — и выберите «Начало
  месячных».»; ниже — «Историю из другого приложения можно загрузить в Настройках → «Резервная копия».»
- **FR-007**: Подсказка MUST соответствовать `docs/design/design.md` (обе темы, контраст ≥ 4.5:1,
  крестик ≥ 44×44).
- **FR-008**: Правило показа MUST быть чистой функцией с тестами, написанными до реализации.

### Key Entities

- **Отметка «подсказка закрыта»** — признак устройства (да/нет), по умолчанию «нет».

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: При свежей установке подсказка видна сразу, без нажатий.
- **SC-002**: После первой отметки месячных подсказка исчезает без перезапуска.
- **SC-003**: Закрыть подсказку — 1 нажатие; после перезапуска она не возвращается.

## Assumptions

- Переключателя в Настройках нет (см. Clarifications).
- Подсказка — только на экране «Календарь».
