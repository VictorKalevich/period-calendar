# Quickstart: проверка фичи 010

## Автоматически

```powershell
npm.cmd test      # hints.test.ts, repository.test.ts, backup.test.ts
npm.cmd run build
```

## Вручную (`npm.cmd run dev`, окно 390×844, светлая и тёмная тема)

1. Очистить данные сайта → «Календарь»: вверху карточка «Как получить прогноз» с крестиком.
2. Нажать вчерашний день → «Начало месячных» → карточка исчезла сразу, появился прогноз.
3. Удалить период («Удалить период») → карточка снова видна.
4. Нажать крестик → карточки нет; перезагрузить страницу → карточки нет.
5. Экспорт резервной копии → в файле нет `firstPeriodHintDismissed`.
6. Крестик — зона нажатия 44×44; текст читается в обеих темах.
