# Quickstart: фича 004

Правила — [data-model.md](./data-model.md), тесты — [contracts/day-dialog.md](./contracts/day-dialog.md).

| # | Сценарий | Ожидание | Требования |
|---|----------|----------|------------|
| 1 | Свежая установка → Настройки | Блок «Записи дня»: «Самочувствие» и «Заметки» выключены | FR-004 |
| 2 | Выбрать день с прогнозом | «{дата} · N-й день», вероятность, ниже фаза; кнопок «Симптомы»/«Заметка» нет | FR-001, FR-002 |
| 3 | Нажать прошлый день (оба выкл.) | Заголовок — дата; только кнопки месячных и «Отмена» | FR-006 |
| 4 | Включить оба → нажать прошлый день | Кнопки месячных, «Самочувствие», «Заметки», «Отмена» | FR-006 |
| 5 | Нажать будущий день: оба выкл. / только «Заметки» | Диалога нет / диалог с «Заметки» и «Отмена» | FR-007 |
| 6 | Записать заметку и самочувствие разным дням; переключать | Точки и сводка — только включённых типов; легенда «Есть записи» — если включён хотя бы один | FR-009–FR-011 |
| 7 | Экспорт → импорт; импорт копии старой версии | Переключатели восстановлены; у старой — выключены | FR-005 |
| 8 | Поиск слова «Симптомы» в интерфейсе | Нигде нет | FR-003 |
