# Feature Specification: Диалог дня, фаза в карточке, «Самочувствие» и «Заметки» по выбору

**Feature Branch**: `004-day-dialog-wellbeing`

**Created**: 2026-10-24

**Status**: Draft

**Input**: User description: "Карточка дня: убрать кнопки «Симптомы» и «Заметка», показать фазу цикла под датой (не при задержке и не без данных). Переименовать «Симптомы» в «Самочувствие» во всём интерфейсе. В Настройках два переключателя «Самочувствие» и «Заметки», по умолчанию выключены, хранятся в настройках и в резервной копии (старые копии — «выключено»). Диалог по нажатию на дату: заголовок — дата; кнопки месячных по таблице А/Б/В; перед «Отмена» — «Самочувствие» и «Заметки», если включены; будущий день — диалог только с ними, если включено хотя бы одно, иначе диалога нет. Выключение не удаляет записи, но скрывает кнопки, сводку и индикатор; индикатор и сводка учитывают только включённые типы; пункт легенды «Есть записи» — только если включён хотя бы один."

## Clarifications

### Session 2026-10-24

- Q: Индикатор записи при разных переключателях? → A: Учитывает только включённые типы: только
  «Заметки» — точка у дней с заметкой; только «Самочувствие» — у дней с самочувствием; оба
  выключены — точек нет. Сводка в карточке дня — тоже только включённые типы.

## Термины

- **Самочувствие** — симптомы и настроение дня (раньше в интерфейсе — «Симптомы»).
- **Заметка** — текст к дню.
- **Переключатели** — «Самочувствие» и «Заметки» в Настройках.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Фаза цикла в карточке дня (Priority: P1)

Под календарём в карточке выбранного дня — дата, день цикла, вероятность и фаза цикла. Кнопок
«Симптомы» и «Заметка» в карточке больше нет.

**Why this priority**: фаза уже рассчитывается, но после удаления экрана «Сегодня» нигде не видна.

**Independent Test**: выбрать день в фолликулярной фазе — под строкой «24 октября · 10-й день»
написано «Фолликулярная фаза»; при задержке фаза не показана.

**Acceptance Scenarios**:

1. **Given** есть прогноз и нет задержки, **When** выбран день, **Then** карточка показывает
   «{дата} · {N}-й день», пилюлю вероятности и ниже — название фазы.
2. **Given** идёт задержка, **When** выбран любой день, **Then** фаза в карточке не показывается.
3. **Given** нет ни одной отметки, **When** выбран день, **Then** фаза не показывается.
4. **Given** карточка дня, **When** она показана, **Then** в ней нет кнопок «Симптомы» и «Заметка».

### User Story 2 - Переключатели «Самочувствие» и «Заметки» (Priority: P1)

В Настройках блок с переключателями «Самочувствие» и «Заметки» (по умолчанию выключены). Они
управляют тем, видны ли эти записи в приложении. Выключение ничего не удаляет.

**Why this priority**: пользовательница сама решает, нужны ли ей эти записи; по умолчанию
интерфейс проще.

**Independent Test**: включить «Заметки», написать заметку, выключить — заметка не видна нигде;
включить — снова видна. Сделать резервную копию и восстановить — значения переключателей
сохранились; импорт старой копии — оба выключены.

**Acceptance Scenarios**:

1. **Given** свежая установка, **When** открыты Настройки, **Then** оба переключателя выключены.
2. **Given** «Самочувствие» и «Заметки» выключены, **When** есть записи за день, **Then** в календаре
   нет точек-индикаторов, карточка дня не показывает записи, в легенде нет пункта «Есть записи».
3. **Given** включены только «Заметки», **When** у одного дня есть заметка, а у другого только
   самочувствие, **Then** точка — только у дня с заметкой; карточка показывает только заметку.
4. **Given** включено только «Самочувствие», **When** те же дни, **Then** точка — только у дня с
   самочувствием; карточка показывает только самочувствие.
5. **Given** оба включены, **When** те же дни, **Then** точки у обоих; карточка показывает всё.
6. **Given** записи сделаны, **When** переключатель выключен и снова включён, **Then** записи на месте.
7. **Given** значения переключателей изменены, **When** сделан экспорт и импорт, **Then** значения
   восстановлены; **Given** резервная копия старой версии без этих полей, **When** импорт, **Then**
   оба выключены.

### User Story 3 - Диалог по нажатию на дату (Priority: P1)

Нажатие на дату открывает диалог с заголовком-датой: кнопки месячных (по таблице А/Б/В фичи 003),
затем «Самочувствие» и «Заметки» (если включены), затем «Отмена».

**Why this priority**: все действия с днём — в одном месте, одно нажатие.

**Independent Test**: для прошлого и будущего дня, внутри и вне месячных, при всех четырёх
комбинациях переключателей сверить, открывается ли диалог и какие в нём кнопки.

**Состав диалога**:

| День | Кнопки месячных | «Самочувствие» | «Заметки» | Диалог открывается |
|------|-----------------|----------------|-----------|--------------------|
| Сегодня или прошлый | по таблице А/Б/В (003) | если включено | если включено | всегда |
| Будущий | нет | если включено | если включено | только если включено хотя бы одно |

**Acceptance Scenarios**:

1. **Given** прошлый день вне месячных, оба выключены, **When** нажат, **Then** заголовок
   «{дата}», кнопки «Начало месячных» (+ условные по 003) и «Отмена».
2. **Given** прошлый день внутри месячных (не первый), оба включены, **When** нажат, **Then**
   «Отметить конец в этот день», «Установить как начало», «Самочувствие», «Заметки», «Отмена».
3. **Given** будущий день, включены только «Заметки», **When** нажат, **Then** диалог с «Заметки» и
   «Отмена».
4. **Given** будущий день, оба выключены, **When** нажат, **Then** день выбран, диалога нет.
5. **Given** диалог открыт, **When** нажато «Самочувствие» / «Заметки», **Then** открывается
   выбор самочувствия / редактор заметки для этой даты.
6. **Given** первый день месячных, **When** «Удалить период», **Then** подтверждение работает как
   в фиче 003.

### Edge Cases

- Переименование: в интерфейсе нигде нет слова «Симптомы» (заголовки, кнопки, подсказки, лист выбора);
  в коде и в формате данных имена (`symptoms`, `SymptomId`) остаются.
- Запись, у которой есть и самочувствие, и заметка, учитывается в индикаторе, если включён хотя
  бы один из её типов.
- Резервная копия новой версии в старом приложении не импортируется («создана более новой версией»),
  как и раньше для любых новых версий формата.
- Выключенный тип по-прежнему экспортируется в резервную копию и восстанавливается.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Карточка выбранного дня MUST показывать «{дата} · {N}-й день», вероятность и под ними
  название фазы цикла (001 FR-019b); при задержке и без данных фаза MUST NOT показываться.
- **FR-002**: Карточка выбранного дня MUST NOT содержать кнопок «Симптомы» и «Заметка».
- **FR-003**: Во всём интерфейсе слово «Симптомы» MUST быть заменено на «Самочувствие».
- **FR-004**: Настройки MUST содержать блок с переключателями «Самочувствие» и «Заметки»; по
  умолчанию оба выключены; значения MUST храниться в настройках на устройстве.
- **FR-005**: Значения переключателей MUST входить в резервную копию; формат копии и схема хранения
  MUST быть версионированы с миграцией; копии и данные прежней версии без этих полей MUST
  получать «выключено».
- **FR-006**: Диалог по нажатию на дату MUST иметь заголовок — дату («24 октября»), MUST содержать
  кнопки месячных строго по таблице А/Б/В фичи 003 (для будущего дня — нет), затем «Самочувствие»,
  если включено, затем «Заметки», если включено, затем «Отмена».
- **FR-007**: Для будущего дня диалог MUST открываться, только если включён хотя бы один
  переключатель; иначе нажатие только выбирает день.
- **FR-008**: «Самочувствие» и «Заметки» в диалоге MUST открывать существующие выбор самочувствия
  и редактор заметки для этой даты.
- **FR-009**: Выключение переключателя MUST NOT удалять записи. При выключенном типе MUST NOT
  показываться его кнопка в диалоге, его часть сводки в карточке дня и его вклад в индикатор записи.
- **FR-010**: Индикатор записи в календаре MUST учитывать только включённые типы (4 комбинации —
  User Story 2, сценарии 2–5).
- **FR-011**: Пункт легенды «Есть записи» MUST показываться, только если включён хотя бы один
  переключатель.
- **FR-012**: Правила состава диалога, видимости записей и показа фазы MUST быть чистыми функциями
  с автоматическими тестами на все комбинации.
- **FR-013**: Спецификации 001/003, макеты (`docs/design/design.md`) и quickstart MUST быть обновлены.

### Key Entities

- **Настройки** — добавляются `showWellbeing` и `showNotes` (логические, по умолчанию «выключено»).
- **Запись дня** — без изменений; «самочувствие» = есть симптомы или настроение, «заметка» = непустой текст.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Отметить начало месячных — по-прежнему 2 нажатия (дата → «Начало месячных»).
- **SC-002**: Открыть самочувствие или заметку для дня — 2 нажатия (дата → кнопка), когда тип включён.
- **SC-003**: Для всех комбинаций (прошлый/будущий, внутри/вне месячных) × (4 комбинации
  переключателей) есть автоматические тесты состава диалога; 100% проходят.
- **SC-004**: После выключения и включения переключателя 100% записей снова видны.
- **SC-005**: Импорт резервной копии прежней версии проходит, оба переключателя выключены.

## Assumptions

- Фаза в карточке — для выбранного дня (не только сегодняшнего); «при задержке» — когда у текущего
  прогноза есть задержка.
- Название блока в Настройках — «Записи дня».
- Лист выбора самочувствия сохраняет группы «Самочувствие» (симптомы) и «Настроение».
