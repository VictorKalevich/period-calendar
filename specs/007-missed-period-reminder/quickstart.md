# Quickstart: проверка фичи 007

## Автотесты

```bash
npm test          # reminders (M1–M10), migrations v4→v5, db (открытие v4), backup (импорт v4 → true)
npm run build
```

Worker не меняется — `npm test --prefix worker` и `wrangler deploy` не требуются.

## Ручная проверка (`npm run dev`)

Синхронизация считает расписание от реального времени; сценарии задержки (M3–M5) проверяются
автотестами, а вручную — отметкой месячных в прошлом так, чтобы прогноз уже прошёл.

1. Настройки → «Напоминания»: три переключателя — «За 2 дня до месячных», «В день овуляции»,
   «Напоминать, если забыла отметить начало месячных» с описанием 13 px `muted`; все включены;
   зона нажатия ≥ 44 px; светлая и тёмная темы.
2. Выключить все три — подписка отключается; включить новый — запрос разрешения/подписка.
3. Расписание (Network → PUT к воркеру): записи `missed-period:…` на «прогноз + 2» 12:00; заголовки
   всех записей «Календарь цикла»; в теле только `id, sendAt, title, body`.
4. Отметить последние месячные так, чтобы прогноз был вчера (задержка 1), — в PUT только
   `missed-period:<прогноз+2>`.
5. Отметить начало месячных — после синхронизации записи на старую дату нет.
6. Импорт резервной копии v4 — переключатель включён.
